### 任务 C：远程仓库应补充的软件说明书

当前 Scrollforge 根目录有 AGENTS.md，但没有面向人类读者的 README.md。按优先级排序：

#### C1. `README.md` —— 项目总览（必写）
- **Scrollforge 是什么**：一句话定位（"EPUB 原生格式的轻量阅读器 + 编辑器 + 翻译工作流"）
- **能做什么（功能矩阵）**：
  - 书架：EPUB / TXT / MD / HTML / FB2 / CBZ 导入 → 3D 书架展示
  - 阅读器：Foliate 内核，分页/滚动模式，6 色高亮，脚注/插图，实时翻译
  - 编辑器（E6）：块级可视编辑（段落/标题/删除标记），内联格式工具条（粗体/斜体/链接），修订列表与回滚，epubcheck 校验
  - 锻造器：ForgePanel 逐段改写 + 翻译 + 注释，整章批量，术语表 + 翻译记忆，版本快照
  - 翻译三通道：阅读器划词（草稿）/ 编辑器段落（正式）/ ForgePanel 整章（带记忆）
  - EPUB 生成：buildEpub 支持分卷层级、内嵌插图、番外/后置页、OPF/NCX/nav 自动生成
- **不能做什么（诚实边界）**：
  - 不支持 PDF / 漫画在线抓取（CBZ 本地导入可）
  - 翻译引擎需要用户自己配置在线 API 或本地模型地址
  - 目前不支持移动端（桌面 only，Windows 已打包，Mac/Linux 理论可跑）
- **技术栈**：Tauri 2 + React 18 + TypeScript + Vite + Rust（zip + quick-xml + serde_json）
- **目录结构**：`app/` 前端 / `app/src-tauri/` Rust 后端 / `.agent/` agent 工作区
- **快速开始**（开发者）：`npm install` → `npm run tauri dev`
- **致谢 / 第三方许可**：foliate-js（阅读器内核，MIT）、zip（MIT）、quick-xml（MIT）

#### C2. `BUILDING.md` —— 构建指南（给开发者）
- Rust 环境要求（Rust 1.80+，Windows 下 MSVC 工具链）
- Node 环境要求（Node 18+）
- 依赖安装：`cd app && npm install`
- 开发模式：`npm run tauri dev`
- 生产构建：`npm run tauri build`（产物在 `app/src-tauri/target/release/`）
- 环境变量（如果有）：`CARGO_HOME` / `RUSTUP_HOME` 必须设置指向 Rust 安装路径（这是用户本机器的约定，其他机器可能不需要）
- 常见问题（epubcheck 需要 Java 17+；ffmpeg 可选）

#### C3. `TRANSLATION.md` —— 翻译三通道工作流（给开发者 + 高级用户）
- 三通道差异表（和 SKILL.md 里一致，但面向人类读者，去掉代码细节）
- Glossary（术语表）格式：CSV，source,target,kind（person/place/org/term）
- Translation Memory（翻译记忆）：JSON，每条原文→译文，用户修订自动覆盖
- 在线引擎配置：API endpoint / API key / model name
- 本地引擎配置：本地 Ollama / vLLM endpoint / model name
- 提示词模板（可在设置面板里改 source/target/style）
- 三通道调用示例（伪代码级别，不是完整代码）

#### C4. `ARCHITECTURE.md` —— 架构图（给维护者）
- Rust side 模块划分：
  - `main.rs` —— Tauri command 注册 + 书库管理 + 翻译引擎调用
  - `forge.rs`（main.rs 内）—— forge.json 读写 + commit_forge + 版本快照
  - `epub_edit.rs` —— unpack_epub / write_blocks / pack_epub / epubcheck
  - `translate.rs`（前端 lib）—— translateOne + TranslateConfig + 提示词模板 + memory
- 前端模块划分：
  - Reader.tsx —— 阅读器主组件
  - EpubEditPanel.tsx —— EPUB 编辑器块级编辑
  - ForgePanel.tsx —— ForgePanel 锻造器
  - AnnotationTools.tsx —— 阅读器工具栏（高亮/笔记/翻译）
- 数据流：EPUB → unpack → scan_blocks_raw → BlockInfo → edit_write_blocks → pack_epub
- forge_epub_index 映射：chapterIndex:paragraphIndex → rel_path + block_index
