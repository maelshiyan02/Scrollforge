## 0.1 骨架：自建 MIT（2026-10-27 第三轮拍板，取代此前"fork Readest"）

**结论：不从任何 AGPL / GPL 项目 fork。用 MIT 栈自建。**

| 层 | 选型 | 许可证 |
| --- | --- | --- |
| 桌面外壳 | Tauri 2 | MIT / Apache-2.0 |
| 渲染内核 | **foliate-js** | **MIT** |
| 排版 CSS | readium/css | BSD-3 |
| UI | React + Vite + Tailwind | MIT |
| 数据 | SQLite + FTS5 | MIT |
| TTS | 系统语音（默认）+ 在线引擎 + 离线音色包 | — |

> **版权红线**：Readest / ReadAware / Koodo 是 AGPL-3.0，Wenku8_Flutter / Calibre 是 GPL-3.0。**可以读它们的代码学架构，不能复制任何一行**。凡"参考 ReadAware 的 `text-chapters.ts`"这类说法，一律理解为"按同一算法思路重写"。

**能省力的与省不掉的**

- 省力的：foliate-js 已有 EPUB/MOBI/KF8/FB2/CBZ/PDF 解析、分页与滚动（`columnize` / `scrolled`）、**竖排（`vertical-rl`/`vertical-lr`）与 RTL 判定**、CFI 定位。
- 省不掉的：书架与导入、SQLite 六张核心表、进度定位、标注系统、搜索、设置系统、转换向导、锻造层与回滚、TTS 编排、内置说明书。

> 两处细节清单见 [分析报告 12.1（能用什么）与 12.2（必须自己写什么）](../analysis/00-开源阅读器横向对比与骨架选型分析.md)。

**参考但不抄**：Readest（工程结构与命令面板）、ReadAware（排版 token 与插件思路）、Koodo（书架密度与右键菜单）、Wenku8（设置信息架构）、Calibre（Edit book 流程）、月读（老板键与透明窗）。

- **只能读、不能抄**：`readest`、`koodo-reader`、`read-aware`（AGPL-3.0）、`calibre`、`foliate`、`wenku8`（GPL）。一旦代码进入本仓库，整个项目被传染为对应许可证。

## 0.7 2026-10-27 第二轮：界面硬约束与产品定位（实机使用后修正）

**定位：不只阅读器，也是编辑器。** 读（统一书架/进度/标注）+ 转（TXT→EPUB 是核心流程，不是附属）+ 改（原文只读，"改写/翻译/注释"落在覆盖层，可 diff、可回滚、可导出）。界面因此有三处入口：书架、导入/转换向导、阅读页右侧"锻造"抽屉。

**八条界面硬约束（不再讨论，直接执行）**

1. 侧栏**收起不隐藏**：左右栏折叠成 48–56px 图标条，上下条折叠成 32px 细条；PC 版不追"全屏只剩文字"
2. 全部按钮**中文文本标签**；纯图标按钮必须有中文 tooltip，tooltip 里带快捷键
3. **预设优先**：阅读模式（单页/双页/连续滚动/沉浸）、排版方案、TTS 音色都给 3–6 个命名预设（如"雾松""浅海"），自定义排在预设之后
4. **高频一级可达**：单页↔双页、字号、主题、目录、听书，必须在"工具栏 / 右键菜单 / 命令面板 Ctrl+Shift+P / 快捷键"中任一路 1 步完成（Readest 已有命令面板与命令注册表，直接复用）
5. **桌面密度**：常显章节名、页码、百分比、当前模式
6. **全中文**：菜单、设置项、错误提示不混英文
7. **TTS 开箱可用**：装完即听，引擎/音色/环境音属于进阶
8. **后台不抢焦点**：导入、转换、预缓存、自动更新一律后台执行

**不要做的**：零 chrome 阅读面、纯图标工具栏、只留一个浮动胶囊入口、把"分栏/双页"藏在二级设置里。

**新增功能（必须做进规格，细节见 [分析报告第十三节](../analysis/00-开源阅读器横向对比与骨架选型分析.md)）**

1. **竖排 + 右到左**：日文轻小说与中文古籍。文字方向 / 翻页方向 / 自动识别三个独立开关；预设"日文轻小说·竖排右→左"。foliate-js 已支持 `vertical-rl`，不用从零写
2. **翻页与滚动多形态**：平移翻页、覆盖翻页、淡入、瞬时、双页跨页（含单↔双一键切）、连续纵向滚动、连续横向滚动、缩放/固定版式；卷页动画列为 P2
3. **彩页处理**：保持原色（默认）/ 融入纸色 / 夜间柔化；彩页单独成页；固定版式书用缩放代替字号
4. **鼠标**：`Ctrl + 滚轮` 缩放 50%–400%（与字号独立，按书记忆）；滚轮翻页或平滑滚动可切；`Shift + 滚轮` 横向
5. **`Esc` 返回上一级**：层级栈（全屏 → 关闭弹层 → 退出锻造 → 回书架）
6. **内置说明书**：`F1` 打开，含快捷键表（从命令注册表自动生成）、每个设置项一句人话解释、"在界面中高亮该按钮"的指引
7. **写回与回滚**：临时文件 → 校验 → 原子替换 → 原文件进 `.history/<bookId>/<rev>`；diff 可看，回滚也生成新 revision
8. **插件要中文化**：不做同名插件系统，改"功能模块开关"（中文名 + 一句说明 + 授权范围），插件设置不塞进主导航

> 界面形态：Readest 的干净阅读区 + Koodo 的桌面级书架密度；设置页学 Wenku8 的编号分节与命名预设。

## 0.10 2026-10-31 下一轮计划（R 系列）：十条反馈的可行性结论

> 本节是**计划**，不是实现记录。2026-10-31 本轮只做可行性分析并写入总计划，下一轮才按本节开工。

### 0.10.1 总体结论

十条反馈**全部可做**，但难度分三档：

- **高可行（现有能力补强，1–2 个阶段内可交付）**：3D 书架背景、上一章/下一章、底部进度条、封面优先、插图/彩页、设置与说明书。
- **中等（要新增数据模型或渲染路径）**：新建书向导的目录结构、书籍前置/后置页、格式矩阵读取、编辑深水区。
- **较高（涉及新引擎与许可/体积取舍）**：PDF 渲染、本地翻译引擎、MOBI/AZW3 写出。

推进策略：**先完善现有功能（R1–R6 + E6）→ 再做翻译（R7）→ TTS 延后**。这与用户"完成现有功能完善后，下一步开发翻译"的要求一致。

   - PDF → EPUB：文字层可提取时做"尽力而为"，扫描版不做 OCR。

|---|---|

| MOBI/AZW3 有 DRM | 只支持无 DRM 文件；遇到 DRM 给中文提示，不破解 |

| 封面优先与"快速续读"冲突 | 有进度直接回原位置；只有无进度/主动返回封面时才展示封面 |
| 进度条在固定版式/滚动模式失真 | 分模式取值：分页用 `fraction`，滚动用 section 进度；验收三种模式 |
