## 2. 数据模型

```ts
export type ThemeMode = 'day' | 'eye' | 'night'

// Prefs 新增
theme: ThemeMode   // DEFAULT_PREFS.theme = 'day'（保持现有观感）
```

- `loadPrefs()` 用 `pick(parsed.theme, THEMES, 'day')` 做白名单，旧存档自动补默认值。
- 持久化沿用 `scrollforge:prefs`（localStorage），不新增存储键。
- 不做 `system` 档（见分析 §4）。

## 3. CSS 变量分层

```
:root                      → day（默认，值等同现状，保证不"变样"）
:root[data-theme="eye"]    → 护眼
:root[data-theme="night"]  → 夜间
```

三层令牌：

| 层 | 令牌 | 说明 |
|---|---|---|
| 引擎 | `--paper` `--bar` | 页面/舞台、外壳条 |
| 表面 | `--surface` `--surface-2` `--surface-3` | 卡片/输入/按钮、悬停、选中 |
| 文本 | `--ink` `--ink-soft` `--muted` | 正文、次级正文、辅助说明 |
| 描边 | `--line` `--line-strong` | 普通、强调 |
| 强调 | `--accent` `--accent-ink` `--accent-weak` | 品牌色、其上文字、浅底 |
| 反馈 | `--danger` `--danger-weak` `--success` `--success-weak` `--warn` `--warn-weak` | 错误/成功/警告 |
| 深度 | `--shadow` `--overlay` `--tip-bg` `--tip-ink` | 阴影、遮罩、hover 提示气泡 |
| 编辑器 | `--ed-bg` `--ed-bar` `--ed-surface` `--ed-surface-2` `--ed-line` `--ed-ink` `--ed-muted` `--ed-accent` `--ed-danger` `--ed-warn` `--ed-ok` `--ed-code` | 仅 EPUB 编辑页 |

具体色值与对比度实测结论见分析 §2（正文 10.25–13.35:1，辅助文字 4.8–4.9:1，均 ≥ WCAG AA）。

## 5. 硬编码色收敛策略

1. 先建令牌层，day 值 = 现状值 → 替换后日间必须"肉眼无差异"。
2. 按频次从高到低映射（`#fff`→`--surface`、`#a35312`→`--accent-ink`、`#fffdfa/#fdfcf9/#fbf8f2`→`--surface`、`#a89f92`→`--muted`、`#5a5148/#4a443c`→`--ink-soft`、`#f1e9dd/#e6e0d4`→`--line`、`#f38ba8`→`--ed-danger` 等），用脚本批量替换后人工复核。
3. **不收敛**：划词 6 色高亮、3D 书架木纹/搁板装饰色（仅夜间整体压暗）、`epub-writer.ts` 内生成的 EPUB 样式（属产物而非界面）。
4. 替换后用 `Grep` 复核 `#fff|#faf|#fdf|rgba(255` 残留，逐条判断是否漏改。

## 7. 风险与备选

| 风险 | 备选方案 |
|---|---|
| 批量替换误伤装饰色/语法色 | 先只替换"结构色"，装饰色保留；截图片区对照复查 |
| 书内自带背景色覆盖注入 | 注入 `html,body{background:...!important;color:...!important}`；正文元素不强改 |
| 3D 书架在夜间灰绿偏脏 | 夜间给 3D 区加一层 `--shelf-base` 令牌，必要时整体 `filter:brightness(.8)` |
| 编辑器浅色化后部分区块对比不足 | `--ed-*` 单独校验，必要时日间编辑器改用 `#F6F6F6` 表面色 |
| PDF/CBZ 白页在夜间刺眼 | 仅舞台变暗；如用户不接受，再加"页面降亮"开关（下一轮） |
