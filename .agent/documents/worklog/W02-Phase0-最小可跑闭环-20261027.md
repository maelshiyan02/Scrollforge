# W02 · Phase 0 · 最小可跑闭环（2026-10-27）

> 阶段：Phase 0 ｜ 规格：`../../specs/00-Phase0-最小可跑闭环.md` ｜ 版本：0.1.0 ｜ 证据截图：`_testdata/shots/`

## 1. 目标

交付一个**能双击打开、能读一本 EPUB、界面全中文**的最小可跑闭环，交付路径固定 `build/Scrollforge.exe`。

## 2. 做了什么

1. **记忆体系**：建 `.agent/{memory,documents,specs}`，主记忆 `MEMORY.md` 压到 ≤3K，正文下沉附录 A01~A07 + `W00` 索引；旧主记忆 17.7K 字符归档到共享层 `_shared/memory/appendices/`。
2. **工程骨架**：Tauri 2 + React 19 + Vite 7 手工搭建（`app/`），`src-tauri` 配置 `bundle.active:false`、release 开 LTO + strip。
3. **渲染内核**：vendor 化 foliate-js（MIT，25 个文件含 LICENSE），`pdf.js` 换成占位实现（Phase 4 再接 PDF）。
4. **Phase 0 功能**：打开 EPUB（含命令行传入路径）、上一页/下一页、单页↔双页、横排↔竖排、分页↔连续滚动、章节名与百分比、进度记忆（`localStorage` 存 CFI）。
5. **图标**：`npx tauri icon icon.png` 生成全套 17 个图标文件。
6. **出包**：`npx tauri build --no-bundle` → 复制到 `build/Scrollforge.exe`。

## 4. 过程中修掉的真问题

1. **进度记忆失效**：`relocate` 回调只在挂载时注册一次，闭包里 `bookName` 永远是 `''`，条件永远不成立 → 改用 `bookNameRef` + `saveEnabledRef`，并在 `init()` 完成后立刻补存一次。
2. **`pdf.js` 动态 import 断裂**：删掉 foliate 的 `pdf.js` 后 Vite 构建报 `Could not resolve` → 补占位实现。
3. **英文报错透出**：foliate 抛 `File type not supported` → 映射为中文提示（"不支持这种文件格式，当前版本只支持 EPUB"）。
4. **截图误判界面缺件**：PowerShell 进程非 DPI 感知，125% 缩放下 `PrintWindow` 只画了左上 80% 区域，误以为状态条没渲染 → 抓图前 `SetProcessDPIAware()`。

## 5. 已知技术债（Phase 0 明确不做）

- 进度存 `localStorage`（AppData 下 WebView2 配置目录），后期迁 SQLite。
- 文件选择用 `<input type="file">`，未接 `tauri-plugin-dialog`。
- 无书架、无 TXT、无转换向导、无锻造层、无 TTS。
- 竖排下双页只显示一栏（章节内容不足两页时正常现象，需更大文本量复核）。
- 视口 1200×820 时左侧留白偏大（`max-inline-size` 未调），Phase 1 调版式时一并处理。
