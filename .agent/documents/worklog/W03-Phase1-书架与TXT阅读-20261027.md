## 1. 本轮目标

把"只能打开一本 EPUB"变成"有书架、能把中文 TXT 读得像书"：导入、分组、排序、删除、章节识别、硬换行熔接、排版调整、目录跳转、进度记忆。

用户明确选择：**本期不接 SQLite，继续 localStorage。**

## 2. 实际改动

### 2.1 Rust 端（`app/src-tauri/src/main.rs`）

| 命令 | 作用 |
|---|---|
| `import_book(path)` | 校验扩展名/大小，复制到 `<应用数据>/books/<id>/source.txt`，写 `meta.json` |
| `list_books()` | 扫描书库；跳过缺 `source.txt` 或 `meta.json` 损坏的目录 |
| `read_book_bytes(id)` | 读副本原始字节（`tauri::ipc::Response`，不膨胀成 JSON 数组） |
| `delete_book(id)` | 删应用数据里的副本，不动用户原文件 |
| `read_book(path)` / `start_args()` | Phase 0 保留，命令行打开 EPUB 不回归 |

- 书目 id 只允许字母、数字、`-`、`_`，做路径穿越防护。
- 新依赖 `tauri-plugin-dialog = "2"`；`capabilities/default.json` 加 `dialog:default`。

### 2.2 前端新增模块

| 文件 | 职责 |
|---|---|
| `src/lib/encoding.ts` | BOM → UTF-8 严格 → GB18030 严格 → GB18030 容错 |
| `src/lib/txt-chapters.ts` | 逐行章节分类、拆行回目合并、目录去重、递增可信度校验、段落熔接、10MB 长文分块兜底 |
| `src/lib/txt-book.ts` | 把章节包装成内存 EPUB（虚拟 loader，不落盘），交 foliate 渲染 |
| `src/lib/typography.ts` | 字号 12–34px、行距 1.5–2.3、首行缩进开关，注入章节文档 |
| `src/lib/progress.ts` | `localStorage` 进度：`lib:<id>` / `file:<name>` 两套 key |
| `src/components/Shelf.tsx` | 网格/列表、分组（全部/最近阅读/未读）、排序（最近阅读/导入时间/书名）、右键菜单、查看信息、删除确认、空书架引导、拖拽遮罩 |
| `src/components/Reader.tsx` | 目录抽屉、排版面板、加载/错误态、单双页/横竖排/分页滚动、快捷键（Esc 逐级后退） |

`App.tsx` 改为路由壳：书架 ↔ 阅读；拖拽导入监听 `onDragDropEvent`；启动参数同时识别 `.epub` 与 `.txt`。

## 4. 过程中修正的问题

1. **验收基线写错**：原计划写"123 回"，实测该书是 **120 回本**；grep 到的 123 行里混了 2 行正文和 1 行重复标题。已同步改 A04 与规格书。
2. **只有"第X回"的空目录项**：前十一回的回目在下一行，首版没合并。新增 `mergeSplitTitle()`，并把正文起点后移。
3. **重复标题落进正文**：去重后第二份标题留在正文开头，新增"剥掉正文开头空行/分隔线/同名标题"。
4. **目录点了没反应**：`view.goTo('text/ch0001.xhtml')` 解析不到，改为完整 `OEBPS/text/ch0001.xhtml`；foliate 内部吞异常，所以不报错。
5. **网格没有多列**：状态类名 `.grid` 与布局类冲突，改用 `view-grid` / `view-list`。
6. **文件对话框自动化失败**：UIA 只把它当 `Pane`，改用 Win32 `WM_SETTEXT`（id 1148）+ `WM_COMMAND`（id 1）。

以上第 2–6 条均已写入 A07（第 24–32 条）。

## 5. 已知欠账（不阻塞本轮）

- 右键菜单与删除只有代码路径，没有自动化截图，需人工点一次。
- 书架只收 TXT，EPUB 仍走「打开 EPUB」。
- 自定义章节正则、目录层级折叠、书签、全文搜索未做（P2+）。
- SQLite 按用户要求推迟；当前 `localStorage` 足以支撑书架规模。
- 连续滚动与竖排的组合尚未逐一截图验证。
