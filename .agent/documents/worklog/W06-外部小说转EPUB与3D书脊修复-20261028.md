## 3. 抓取与清洗

- **目录来源**：WordPress Madara 主题，章节目录由 JS 渲染；`wp-admin/admin-ajax.php` 与 `/wp-json/` 均不给章节列表。改用 **headless Chrome + CDP**（独立 profile，后台、不弹窗）读 `.wp-manga-chapter`，得到 132 条（站点倒序）。
- **正文来源**：`chapter-N/` 页面 `div.reading-content > div.text-left` 已是服务端直出，HTTP 直取即可；用 CDP 渲染同一章对照，首/末段与段落数一致（第 73 章），证明无 JS 依赖缺失。
- **清洗**：删 `script/style/iframe/ins/noscript`、清空广告 div；只保留 `p / h2 / h3 / blockquote` 与 `em / i / strong / b / br / sup / sub`；去重复标题、上下章链接、评论、页脚。
- **结果**：132/132 全部成功（0 失败），1,224,239 字符 / 215,515 词；全书章节内无插图（`imgs=0`），因此插图无需下载。

## 4. EPUB3 构建

- 结构：`mimetype`（第一个条目、`ZIP_STORED`、无 extra）→ `META-INF/container.xml` → `OEBPS/content.opf` / `nav.xhtml` / `toc.ncx` / `styles/style.css` / `images/*` / `text/*.xhtml`。
- spine 顺序：`cover.xhtml`（正式封面，`properties="cover-image"`）→ `info.xhtml`（作品信息）→ `cover-gallery.xhtml`（其他版本封面）→ `ch0001`…`ch0132`。
- nav 条目 134（2 个前置页 + 132 章），NCX 134 个 navPoint 兜底；`dcterms:modified` 无毫秒；`dc:language=en`。
- **多封面**：5 张全部入库 `OEBPS/images/`，正式封面 `cover.jpg`，其余 `cover-alt-1..4`，画廊页每张配来源说明。

## 5. 自检与实测

- `check_epub.mjs`（Node 自写 ZIP 解析）：mimetype 位置/存储方式/无 extra、container→OPF、`dcterms:modified` 格式、`cover-image` 唯一、manifest 全命中、spine 首项封面、nav/NCX 无死链且条目数相等、章节 xhtml 132、图片引用 0 死链 —— **全通过**。
- `check_content.py`：xhtml/opf/ncx XML 全部可解析；无广告/站点导航残留；无首段重复标题；无过短章节。
- **第三方独立解析**（`ebooklib 0.20`，非本项目代码）：spine 135、toc 134、章节 xhtml 132、图片 5 张、`images/cover.jpg` 515,184 字节、第 1 章标题 `Chapter 1`、第 132 章 `Epilogue - Part 4` —— 全部与前两项一致。

- Scrollforge 实测（debug 版 CDP，全程后台）：
