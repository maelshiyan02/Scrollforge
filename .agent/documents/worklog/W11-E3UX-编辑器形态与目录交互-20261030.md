## 三、本轮修掉的三个真 Bug

1. **`.toc-list` 类名撞车**：阅读器目录抽屉的 `.toc-list button { display:block; width:100% }` 命中编辑器里的抓取/折叠按钮，把行撑到 1150px 宽、标题框挤到视口外（x=2343）。编辑器列表改名为 `.toc-tree` 后布局恢复。
2. **`withSiblings` 把「父路径」当「节点路径」**：`if (p.length === 1) return fn(nodes)` 让 `[0]`（根节点）被当成根列表，导致第二层的上移/下移/降级/拖拽全部作用在根层，静默无变化。拆成 `withSiblings`（节点路径）+ `withChildren`（父路径），三个调用点改掉。
3. **`field-sizing: content` 与 flex 的交互**：标题框从 `<input>` 换成单行 `<textarea rows={1}>`（Enter 直接失焦），配合 `field-sizing:content` + `min-height:1.55em` 才能「字号变大 / 字数变多时自动撑高」。

## 五、残留

- 段落块编辑目前是**雏形**：只支持直接改文字、「应用到源码」合并回 XHTML；图片/图形以占位显示，结构性操作（拆合段、改标签、增删块）留给 E4。
- 目录切换标签或关闭编辑器会丢掉未写回的树改动（与既有行为一致，靠顶部「写回目录」落盘）。
