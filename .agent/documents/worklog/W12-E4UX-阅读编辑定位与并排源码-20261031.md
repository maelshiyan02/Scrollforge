# W12 · E4-UX：阅读↔编辑自动定位 + 并排源码（E4）

- 日期：2026-10-31
- 阶段：E4（段落预览 + 源码并排）/ E4-UX（三条体验修正）
- 产物：`build/Scrollforge.exe`（4,272,640 字节 / 2026-10-31 12:32:51）

## 一、用户反馈（3 条）

1. 阅读 → 编辑不应停在空白等选文件，要自动打开当前阅读章节并滚到当前段落。
2. 编辑页左上角「编辑 EPUB」的文件类型应随当前文件变化（EPUB / TXT / 其它电子书）。
3. 段落切面的文字框也要 Ctrl+滚轮缩放（源码框、目录框已有）。

## 二、实现

### 1. 阅读 → 编辑自动定位

- `Reader.tsx`
  - 新增 `lastLocRef` 保存每次 `relocate` 的 detail（含 `range`）。
  - 新增 `seedFromReading()`：点「编辑」时取当前可见章节
    - 章节：`view.renderer.getContents()[0].index` → `view.book.sections[index].id`
      （注意：`sections[i]` 的字段是 **`id`**，不是 `href`；`lastLocation` 里也**没有 `index`**）
    - 段落：`lastLocRef.current.range` 的 `startContainer` 上溯到 `body` 直接子元素，取其下标。
  - 把 `{ href, block }` 作为 `editSeed` 传给 `EpubEditPanel`（`initialHref` / `initialBlock`）。
- `EpubEditPanel.tsx`
  - `findEntryByHref()`：用 href 的路径后缀匹配 zip 内完整路径（`decodeURIComponent` + 小写兜底）。
  - 解包完成后自动 `edit_read_file` 打开该章节、切到「段落」标签。
  - `pendingBlockRef` 一次性队列：blocks 渲染完成后按 `getBoundingClientRect` 差值滚到目标块，并加 `.blk-focus` 高亮 1.6s。

实测：阅读到 `外传二-6 39%` → 编辑，自动打开 `EPUB/text/ch150.xhtml`（73 块），`scrollTop 1837`，可视首块下标 25。

### 2. 编辑页标题随文件类型变化

- 标题由 `epubPath` 扩展名推导：`编辑 ${ext.toUpperCase()}`（EPUB / TXT / FB2 …），不再写死。

### 3. 段落切面 Ctrl+滚轮

- 新增 `blockFont`（11–34px，默认 15）+ `blockCanvasRef`，`{passive:false}` + preventDefault + stopPropagation。
- `.block-page` 用 `style={{ '--blk-font': ... }}` 驱动 `.blk-body { font-size: var(--blk-font, 15px) }`。
- 并排源码框用独立 `srcFont`（9–28px），同样支持 Ctrl+滚轮。

实测：Ctrl+滚轮向上两次 15 → 17px，源码框仍 12px；普通滚轮只滚动、字号不变。

### 4. E4：预览 + 源码并排

- 段落视图新增 `.block-main`：左预览 `.block-canvas`、右源码 `.block-source`（默认开启，可「收起源码」）。
- 双向同步：
  - 预览 → 源码：沿用「应用到源码」（块内改动合并回 `currentFile.text`）。
  - 源码 → 预览：`handleSplitSourceChange` 700ms 防抖后 `setBlockVersion` 重建；若段落有未应用改动则跳过，改由「刷新预览」按钮确认执行。
- 非 XHTML（style.css / OPF 等）走 `blockError` 兜底，给「切到源码视图」按钮；并排源码框仍可直接编辑。
- 计划书 E4 行按现状改写，并新增 E4-UX 行。

实测：预览追加 `【ZZTEST】` → 应用到源码，右侧 textarea 出现该串；源码改 `ZZTEST2` → 2s 内左侧预览同步。

## 三、踩坑（已写进 A07）

1. `foliate` 的 `relocate` detail **不含 `index`**（`lastLocation = {...progress, tocItem, pageItem, cfi, range}`），章节索引必须从 `view.renderer.getContents()` 拿。
2. `book.sections[i]` 的主体字段是 `id`（= 相对 OPF 的 href），`href` 不存在；且 sections 经 `filter(s => s)`，索引与 spine 原序可能错位，必须走渲染器索引。
3. `getContents()` 在分页模式下返回 `[{ index, doc, overlayer }]`，`index` 与 `book.sections` 同序。
