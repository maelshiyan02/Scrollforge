## 一、目标

只做三条体验补强，不改架构、不加依赖：

1. 3D 书架从深棕木纹换成贴合软件的黄白基底，书脊轴测投影逻辑不动。
2. 阅读器顶栏补「上一章 / 下一章」章级跳转，首末章禁用并给中文提示，竖排方向跟随阅读方向。
3. 底部状态栏叠一条 Thorium 风格细进度条，可点击、可拖拽，三种阅读模式都可用。

明确不做：R2–R7、E6，封面优先、向导目录、格式矩阵、插图全屏、设置/说明书均未触碰。

## 二、实现

### 2.1 3D 书架换底（纯 CSS）

文件：`app/src/styles.css`

- `.rack-viewport`：深棕木纹渐变 → 暖白背板（`#f7f3ea → #f2eddf 44% → #e9e1d0`）+ 径向光 + 极轻纸纹；边框与内阴影改为低饱和暖灰。
- `.rack-board`：木色降饱和提亮（`#e6cba4 → #d0ac80 44% → #bb9264`），前沿立面 `#c39c6b → #9c7448` 做厚度。
- `.rack-tail`：文字改深色 `#8b7b63`，补浅木色书挡立板（`::before`，不新增 DOM）。
- `.rack-index`：文字改深色 `rgba(90,74,48,0.55)`。
- `.book-slot:hover .book3d`：黑色 0.5 投影 → `drop-shadow(0 14px 16px rgba(80,60,38,0.26))`；抽书两阶段投影同步减淡到 0.24 / 0.28。
- 未改：`.rack-shelf` 的 `--dx / --dy / --skew` 轴测参数、书脊宽度/间距算法、`Shelf3D.tsx` 交互。

### 2.2 上一章 / 下一章

文件：`app/src/components/Reader.tsx`

- 新增 `hrefKey()`（去 `#` 片段 + `decodeURIComponent`）与 `chapterIndexOf()`：先按 `detail.tocItem.href` 定位，找不到再用 `detail.section.current → book.sections[i].id` 兜底。
- 新增 `jumpChapter(dir)`：取 `tocRef.current` 与当前下标，越界直接返回，否则 `await view.goTo(toc[idx + dir].href)`。
- 顶栏新增两个 `icon-only` 按钮：`aria-label="上一章 / 下一章"`；首/末条 `disabled`，`data-tip` 分别给「已经是第一章 / 已经是最后一章」；无目录时给「这本书没有目录」并禁用。
- 竖排时图标换向（上一章 `skip_next`、下一章 `skip_previous`），文字标签仍为「上一章 / 下一章」。
- 分组目录天然跳过：`toc` 只由 `flattenToc()` 过滤后的可跳转条目组成，未另写过滤。

### 2.3 底部阅读进度条

文件：`app/src/components/Reader.tsx`、`app/src/styles.css`

- `FoliateView` 类型补 `goToFraction(fraction)`；使用内核已有的 `view.goToFraction()`（`view.js` L471）。
- 状态栏上方新增 `.read-progress`（12px 高命中区、内部 4px 轨道）：浅灰轨道 + 橙色渐变已读 + 可拖动圆点 + 拖动气泡。
- `pointerdown` 捕获，移动只更新本地 `dragPercent`，`pointerup` 才 `goToFraction`；拖动期间显示 `xx%`，松手后以 relocate 回填的真实 fraction 为准。
- 进度条上 `stopPropagation`，并把 `.read-progress` 加进滚轮排除表，不抢键盘/滚轮。
- `fractionKnown` 为 false（无 fraction 能力）时隐藏进度条，不报错。

## 七、R1-UX 补丁：底栏漏缝（2026-10-31 追加，v0.6.3）

用户反馈：阅读进度底栏在 125% 缩放的最大化窗口下，进度条与状态栏之间露出一条纸色缝（截图 2557×212）。

### 7.1 原因分析

- 对用户截图逐行采样：自下而上为 `--bar`(242,239,233) 状态栏 → 约 5.6 CSS px 的 `--paper`(250,249,246) 缝 → 12px 进度条（轨道橙色居中）→ 纸色阅读区。缝隙颜色精确等于 `html/body/#root` 的 `--paper`，说明露出的是根容器底色。
- 底栏原先由两个独立 flex 区块组成：`.read-progress`（12px）与 `footer.status`（30px）。两者各自绘制背景，在 DPR=1.25、窗口高度为分数 CSS（最大化工作区 1113.6px）时，相邻边缘按设备像素取整后出现未覆盖条带，根容器纸色从条带透出。
- 本机用 CDP 复刻同一几何（2046×1113 → 截图 2558×1392）后，CSS 矩形始终连续（`progress.bottom === status.top`），说明缝隙来自绘制/合成取整而非布局数值，且与具体 WebView2/DPI 环境相关。

### 7.2 修复

- `styles.css`：进度条与状态栏并入同一个 `.read-bottom`（`flex:none; height:42px; background:var(--bar)`）；`.app` 也加 `background:var(--bar)`，任何残余条带只会显示底栏色，结构上不可能再露出纸色。
- `Reader.tsx`：把 `.read-progress` 与 `footer.status` 包进 `.read-bottom`；进度条宽度/拖拽/气泡逻辑一行未改。

### 7.3 实测

- 2048×1152：底栏 1387.5–1440 设备像素逐行扫描，paper 像素恒为 0（仅 1 行 `--line` 边框）。
- 2046×1113（复刻用户几何）：`read-bottom 1071.6–1113.6`、`progress 1071.6–1083.6`、`status 1083.6–1113.6` 连续；截图底部 40 行扫描 paper=0（`r1ux_2046x1113.png`）。
- 交互回归：合成 PointerEvent 拖 22%→61%，章节 `423화 → 427화`；拖动气泡 `35%` 位于 y=757–776（进度条上方、未被裁剪，`r1ux_bubble.png`）。

## 八、GUI 操作步骤（给非开发者）

1. 双击 `D:\AI Coding Project Management\Scrollforge\build\Scrollforge.exe`。
2. 在书架右上点「3D 书架」按钮，查看新的黄白底色书架。
3. 双击任意一本书进入阅读。
4. 顶栏点「下一章」跳到下一章开头；点「上一章」回到上一章开头。
5. 把底部细进度条拖到中间，松手后看状态栏百分比与章节名变化。
6. 关闭这本书再重新打开，确认回到刚才的位置；右上点「横竖排切换」确认章级按钮方向随竖排换向、文字仍是「上一章 / 下一章」。
