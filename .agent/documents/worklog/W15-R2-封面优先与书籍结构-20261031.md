## 一、目标

1. 阅读器初始化不再无条件跳过 `cover/titlepage/nav`：无历史进度时停在封面，有进度时回原位。
2. 封面页底部给「开始阅读」，点击进目录第一条正文；Esc / 返回书架不变。
3. 生成器输出标准书结构：封面 → 书名页 → 简介/版权 → 目录 → 正文 → 番外/后记；nav 与 ncx 两级。
4. 阅读器目录树显示分组层级。

## 二、实现

### 2.1 阅读器封面优先（`Reader.tsx`）

- 删除原「无条件跳过 nav/cover/titlepage」块。
- 新增 `findCoverHref`（先 nav 后 spine）、`findFirstBodyHref`、`isCoverSection`。
- 前置页正则：`cover|title_?page|titlepage|intro|about|preface|foreword|nav|toc|contents`。
- 落位：`saved.cfi ?? coverHref ?? firstBodyHref`；CFI 失效时清进度、重载后仍按封面优先落位。
- `relocate` 持续更新 `onCover`，离开封面即隐藏浮层。
- 「开始阅读」浮层：`.stage` 内绝对定位 `bottom: 28px`，`startReading()` 调 `view.goTo(firstBodyRef.current)`。

### 2.2 生成器标准结构（`epub-writer.ts`）

- `buildEpub()` 重写：封面 → 书名页 → 简介/版权（有内容才生成）→ 目录页 → 章节 → 番外/后记。
- 新增 `pageXhtml / buildTitlePageXhtml / buildIntroXhtml / buildContentsXhtml / buildBackMatterXhtml`、`backFile()`、`pageLabels()`（中英文固定文案）。
- nav：`<span>前置</span>` / `正文` / `后置` 三组两级嵌套；ncx 同构，`dtb:depth=2`，playOrder 先父后子递增。
- OPF：`dc:contributor`（`refines` + `role=trl`）、`dc:description`、`dc:rights`。
- spine 顺序：cover-page → titlepage → intro → contents → 章节 → back-NN。
- 内嵌 `contents.xhtml` 链接章节与后置页，作为书内可读目录。

### 2.3 目录分组（`Reader.tsx` / `types.ts` / `styles.css`）

- `TocEntry` 增可选 `group`；`flattenToc` 保留无 href 的分组节点（`group: true`）。
- 目录树：分组渲染为不可点的 `.toc-group span`（12px 缩进），子项 26px 缩进。
- `jumpChapter` 逐项跳过 `group`，上一章/下一章不会落到分组标题。

### 2.4 向导字段（`NewBookWizard.tsx` / `styles.css`）

- 第 1 步：译者、简介、版权（textarea）。
- 第 2 步：番外/后记列表（标题 + 正文，可增删）。
- 生成时组装 `backMatter` 并传入 `buildEpub`。
- CSS：`.nb-field textarea`、`.nb-area`、`.nb-subhead`。

## 六、踩坑

- 大块 `old_string` 重写 `buildEpub()` 易失配：改为整文件 `Write` 重建，逐段保留原有样式与章节模板。
- 嵌套 nav 的 `<span>` 分组：foliate-js `parseNav` 会把 `<span>` 当作 label、`subitems` 正常解析，但 `href` 为 null；`flattenToc` 需保留分组节点才能显示层级。
- 目录点击后自动关闭面板，连续 CDP 操作需重新打开目录。
- 复制书库 EPUB 以新文件名可得到无进度的新 id，用来验证「无进度停封面」，避免清用户进度。

## 七、GUI 操作步骤（给非开发者）

1. 打开 `build\Scrollforge.exe`。
2. 双击带封面的书：应先看到封面，底部出现「开始阅读」。
3. 点「开始阅读」：进入第一章。
4. 点顶栏「目录」：可见「前置 / 正文 / 后置」分组，点「番外 / 后记」可跳转。
5. 关闭再打开同一本书：应回到刚才位置，不再回到封面。
