## 一、目标

1. 向导第 2 步升级为「结构 + 章节」：章节类型（封面 / 书名页 / 简介 / 目录 / 正文 / 番外 / 后记）；目录层级（拖拽排序、升/降级、合并/拆分）；章节插图。
2. 草稿模型由 `{title,text}[]` 升级为树形节点，`buildEpub()` 输出嵌套 nav/ncx 与对应 xhtml。
3. 与 E3 目录编辑器共用交互范式（工具栏、同层拖拽），避免两套操作手感。
4. 验收：三层目录产物 `epubcheck 0 errors` 且目录可跳转；前言/后记/番外各 1 页，顺序与向导一致。

## 二、实现

### 2.1 生成器（`epub-writer.ts`）

- 新增 `EpubTreeNode`：`{ title?, paragraphs?, image?, children? }`；`buildEpub(chapters, meta)` 优先使用 `meta.structure`，缺省回落到扁平 chapters。
- `emitNodes()` 递归建 link 树；分组节点无自有页面时，在首个子页写唯一锚点 `sf-gN`，分组 `content src = 首子页#锚点`，避免 NCX 同一 target 不同 playOrder 触发 `RSC-005`（R2 遗留问题一并修复）。
- 前置/后置页渲染晚于 link 树，新增 `extraPageAnchors: Map<string,string[]>` 先收集锚点，渲染每页时统一写入。
- nav 用 `<li><span>分组</span><ol>`；ncx 递归 `navPoint`，`dtb:depth = 1 + linkDepth`（本次产物为 4）。
- 章节插图：`images/illust-NN.<ext>` + `<figure class="illust"><img/></figure>`；封面仍走既有 `cover-page.xhtml`。

### 2.2 向导（`NewBookWizard.tsx`）

- 数据模型：`DraftNode { id, volume, title, text, image, children }`；纯函数 `walkNodes/findNode/locateNode/mapNode/removeNode/insertNear/replaceSiblings/treeStats/toEpubTree`。
- 操作：添加章节（选中分卷时成为其子项）、添加分卷、同层拖拽排序（`pointerdown` 手柄 + `elementFromPoint` + `data-node-id`）、降级（最多三层）、升级、合并（两个无子项非分卷章节）、拆分（段落中点、标题加「（续）」）、插入/移除插图（`invoke('read_book')` + objectURL）。
- 工具栏：`N 章 · M 个分卷 · X 字` 统计、自动页 chips（封面/书名页/简介/目录/正文/后置，`.nb-chip.on/off`）、导入 TXT·MD·HTML。
- 生成：`buildEpub([], { …, structure, backMatter, stylePreset, cover })` → 原生保存对话框 → `invoke('save_epub')` → 通知并打开。

### 2.3 样式（`styles.css`）

- 新增 `.nb-structure`（卡片浅底）、`.nb-structure-head`、`.nb-auto-pages`、`.nb-chip/.on/.off`、`.nb-tree-head`、`.nb-node-wrap`、`.nb-node`（hover/sel/volume/drag-src/drop-before/drop-after）、`.nb-drag-handle`、`.nb-kind`、`.nb-illust`（54×54 缩略图）。

## 五、偏差与原因

- 本次 GUI 验收未选封面：向导封面是独立可选图片，未选时按设计不生成封面页；封面生成链路由生成器单测（带 cover 的 `r3-check.epub`）覆盖。
- 验收要求的「前言」落在自动页「简介」(`intro.xhtml`）上，与计划书章节类型「简介」一致。
- `additionalBrowserArgs` 删除后构建尚未显式 touch `build.rs`（命令路径写错为 `app\app\src-tauri`），但 `tauri.conf.json` 变更触发 build script 重跑；新 exe 实测 9222 已关闭。

## 六、踩坑

- Tauri 原生对话框是主窗口内 `#32770` 子窗口，UIA 顶层看不到；文件名控件打开 `1148` / 保存 `1001`；按钮 `ControlType=Pane`，只能用 `WM_SETTEXT + BM_CLICK`。
- NCX 同 target 不同 playOrder → `RSC-005`；分组锚点 fragment 不存在 → `RSC-012`。
- 向导遮罩导致 CDP 坐标点击误关向导：改页面内 `el.click()` 驱动。
- 详见 A07 §26（203–210 条）。

## 七、GUI 操作步骤（给非开发者）

1. 打开 `build\Scrollforge.exe`，书架顶栏点「从零新建一本书」。
2. 第 1 步填书名/作者，点「下一步」。
3. 第 2 步：点「添加分卷」，选中分卷后点「添加章节」；用卡片右侧把手上下拖动排序；用升降级按钮调整层级。
4. 章节卡片点「插图」选图片；「与上一章合并」「从中间拆成两章」在需要时使用。
5. 点「添加后置页」写番外/后记。
6. 点「生成 EPUB」，选择保存位置；生成后自动进入编辑层，可在阅读视图目录中查看分卷层级并跳转。
