# W18 · R5 · 插图与彩页（反馈 ⑦）

> 上级索引：`../../memory/appendices/W00-工作日志索引.md`

## 一、目标

按计划书 §0.10.3「R5 · 插图与彩页」：

1. **EPUB / CBZ / PDF** 内嵌图片正常渲染；点击图片弹出全屏查看（缩放、左右切换、Esc 关闭）。
2. 保留现有「彩页」画廊；固定版式书用**整页缩放**而不是改字号。
3. TXT / MD 这类无内嵌图的格式给出说明，不假装支持。

验收：
- 含插图 EPUB、CBZ 漫画各实测 1 本；
- 全屏看图可缩放 / 关闭；
- 画廊不重复。

## 二、做了什么

- **画廊扩到 CBZ/ZIP**：重写 `app/src/lib/gallery.ts`。EPUB 分支仍是 `makeBook` + manifest 图片（`MIN_BYTES 24KB`、`MIN_SIDE 320` 过滤 + 按字节降序）；新增 `readComicImages()` 用 `zip.js` 解包，只收 `jpg/jpeg/png/gif/bmp/webp/svg/jxl/avif`，按 `Intl.Collator({numeric:true})` 自然排序保留漫画页序，最多 120 张；`readPageImages()` 按格式分派（epub / cbz / zip），ZIP 当 CBZ 处理。
- **全屏看图 `ImageViewer.tsx`（新建）**：
  - 缩放 0.25~4（工具栏 ±、滚轮 `0.87/1.15`、点图片在 1↔2 倍间切换），拖拽平移（>3px 判定为拖动则不平移误触关闭）。
  - 左右切换、`index+1 / len · W×H` 说明、点背景或右上角关闭；Esc 由 Reader 全局键盘统一处理。
  - `index` 变化时重置缩放与偏移；`applyZoom` 用 `zoomRef` 同步，偏移按比例缩放，避免异步状态读到旧值。
- **`Reader.tsx`**：
  - 新增 `viewer` 状态与 `imageClickRef`：`load` 时给每个 doc 挂 `click` 监听，命中 `naturalWidth/Height ≥ 64` 的 `img` 时，收集当前 doc 全部可用图，`preventDefault/stopPropagation` 后打开查看器（`插图 N`）。
  - 固定版式识别：`view.book?.rendition?.layout === 'pre-paginated'` → `fixedLayout`，工具栏排版按钮改为「整页缩放」（图标 `zoom_out_map`）。
  - 整页缩放：`applyFixedZoom()` 把 `fit-page / fit-width` 直接写 `renderer.setAttribute('zoom', mode)`；百分比模式按 `pageSizeOf(doc)`（viewport meta → 首图 naturalSize）算 fit 再乘以倍率，写成绝对 scale；`ResizeObserver(host)` 与缩放状态变化都重新应用。
  - 键盘：`viewer` 打开时优先处理 Esc / → / PageDown / ← / PageUp，其后 `return`，不干扰阅读器原翻页逻辑。
  - Ctrl+滚轮：固定版式下改 `fixedZoom`（0.5~2.5，0.1 步进），非固定版式仍改字号。
  - 彩页入口不再 `disabled`，按格式给中文 `data-tip`：PDF「固定版式，用整页缩放查看」；TXT/MD/HTML「纯文本格式，没有内嵌插图」；非书架来源「彩页浏览只支持从书架打开的图书」。
  - 画廊缩略图点击 → 同一查看器（带全部画廊项）；`releaseImages` 在 `galleryItems` 变化时清理 blob。
  - 排版面板拆两套：固定版式显示 `适应整页 / 适应页宽 / 125% / 150% / 200%` + 说明；普通书仍是字号/行距/缩进。
- **`styles.css`**：新增 `.image-stage`、`.image-viewer img`、`.viewer-close`、`.viewer-tools`、`.viewer-zoom`、`.zoom-modes`、`.zoom-mode`、`.typo-hint`。
- 版本三处同步 `0.10.0`。

## 四、偏差与原因

- **双击图片缩放未生效**：`onPointerDown` 里的 `preventDefault()` 抑制了兼容鼠标事件，`dblclick` 不触发；且单击 pointerup 已做 1↔2 倍切换，双击会连切两次归零。最终删除 `image-stage` 的 `onDoubleClick` 与 `img` 的 `onClick`，缩放改由工具栏按钮、滚轮、点图切换承担。
- **EPUB 画廊只有 1 张**：首测用的 `ending-maker.epub` 只有封面图；换成含 `cover-gallery.xhtml`（5 张 img）的样本后满足「含插图 EPUB」实测。
- **封面文件名变成 `.css`**：该扁平样本只有 `cover.jpg`，既有扁平封面抽取的小问题（与 R5 无关）；测试后已删残留封面，不影响交付。
- PDF 的内嵌图片未单独做"图内点击"（PDF 画布渲染不暴露独立 `img` 节点）；按计划书"固定版式用整页缩放"处理，不标为已支持点击看图。
