## 一、目标

按计划书 §0.10.3「R6 · 设置、版本与说明书」：

1. **版本号单一来源**：`tauri.conf.json` → 设置「关于」动态读取，消除硬编码。
2. **功能页升级为功能注册表**：每项含中文名、状态（已上线/实验中/规划中）、开关与独立设置入口。
3. **每功能设置**：阅读（翻页/双页/竖排/彩页）、书架（视图/排序/3D 背景）、编辑（字号/自动重建/保存策略）、转换（预设/输出目录）、翻译（引擎/术语表）、实验。
4. **F1 内置说明书**：快捷键表 + 每个设置项一句人话解释 + 入口位置指引；从注册表生成，避免文档与界面漂移。

验收：
- 关于页版本与 `tauri.conf.json` 一致；
- 每个已上线功能在设置里至少 1 个可调项；
- F1 可打开且条目与界面一致。

## 二、做了什么

- **`app/src/lib/prefs.ts`（新建）**：设备级扁平偏好 `Prefs`（`readerFlow / readerDoublePage / readerVertical / shelfView / shelfSort / editorBlockFont / editorSrcFont / editorAutoRebuild / editorCreateRevision / convertPreset / convertIndent / convertCenterHeading / experimentalFixedWheelZoom`），存 `localStorage["scrollforge:prefs"]`；`loadPrefs()` 校验枚举与数值区间，新键缺失时回落旧书架键 `scrollforge:shelf:view|sort`，不迁 Rust `AppSettings`。
- **`app/src/lib/features.ts`（新建）**：功能注册表单一真相。8 个条目（阅读与彩页 / 书架 / 编辑 / 转换与新建书 / 锻造 / 翻译 / 朗读 / 实验），每条含 `icon / title / status / where / desc / settings`；设置项分 `toggle / select / number / note`（`note.action: 'storage'` 可直接跳文件夹页），规划中条目 `disabled`。另导出 `STATUS_LABEL` 与 `SHORTCUTS`（7 条快捷键）。
- **`app/src/components/HelpDialog.tsx`（新建）**：说明书弹层三节（快捷键表、功能与设置、使用提示），功能/设置全部遍历 `FEATURES`；底部「打开设置」「知道了」，右上角关闭。
- **`SettingsDialog.tsx`（重写）**：新增 `prefs` 与 `draftPrefs`；「功能」页遍历注册表渲染卡片（图标、标题、状态标签、说明、入口位置）与 `SettingRow` 控件；侧栏底部「说明书（F1）」，关于页「打开说明书（F1）」；版本改用 `getVersion()`，删除硬编码兜底，读不到时显示「读取中…」。
- **`App.tsx`**：新增 `prefs` 状态与 `updatePrefs`（写 state + localStorage）；窗口级 F1 监听开关说明书；保存设置时同时落 `prefs`；把偏好下发 Shelf / Reader / NewBookWizard / ConvertWizard，设置与说明书互相跳转。
- **`Shelf.tsx`**：视图与排序初值改读 `prefs`，切换时回写 `onPrefs` 并跟随外部变化；设置按钮 tooltip 改为「功能开关与说明书」。
- **`Reader.tsx`**：初值读 `prefs`（翻页方式/双页/竖排），`prefsRef` 供运行时判断；正文 doc 与脚注 doc 的 `keydown` 增加 F1 转发（iframe 内按键不会冒泡到窗口）；固定版式 Ctrl+滚轮受 `experimentalFixedWheelZoom` 控制；编辑器四项目偏好透传。
- **`EpubEditPanel.tsx`**：新增 `initialBlockFont / initialSrcFont / autoRebuild / createRevision`，段落预览与源码初值、源码停顿自动重建、保存生成 revision 均由设置控制。
- **`NewBookWizard.tsx` / `ConvertWizard.tsx`**：分别接收 `initialPreset`、`initialIndent / initialCenterHeading` 作为向导初值。
- **`styles.css`**：删除旧「功能占位」样式，新增 R6 设置功能页（`.feature-list / .feature-card / .feature-tag / .feature-setting / .feature-toggle / .feature-select / .feature-number` 等）与说明书（`.help-modal / .help-head / .shortcut-table / kbd / .help-feature / .help-tips / .help-actions`）。

## 四、偏差与原因

- **没有改 Rust `AppSettings`**：这些是设备级偏好（视图、字号、默认翻页），不入书库设置；用 localStorage 可避免后端字段迁移与旧配置兼容成本。设置保存仍走原 `save_settings`，偏好单独落盘。
- **规划中的翻译/朗读只做入口占位**：R7 才落地，开关置灰并写明「当前不生效」，不假装可用。
- **ConvertWizard 初值只做类型与接线验证**：`initialPreset / initialIndent / initialCenterHeading` 由 App 透传、`tsc` 通过；未再单独改偏好重启 GUI 复测向导（与阅读/编辑偏好的透传路径相同）。
- **说明书关闭按钮未复用 `.viewer-close`**：该样式是为深色看图器做的绝对白色按钮，改用 `.help-close` 放在浅色头部。
