# W22 · R6-UX · 设置面板拖动缩放 + 翻译源/目标语言设置 + 高亮颜色扩展

> 上级索引：`../../memory/appendices/W00-工作日志索引.md`
> 分类：查漏补缺（R6 设置面板 UX 迭代 + 翻译设置项 UX 扩展）

## 一、改动原因

R6 设置面板上线以来，三个反馈持续出现：

1. **点主界面就消失**：设置面板作为完整工作面板（不是快捷弹层），主界面点击应该继续显示，只有显式关闭按钮 / Esc 才关闭。
2. **窗口尺寸固定 800×610 不能调**：大屏用户希望拉宽看更多功能项，小屏笔记本希望拉矮让底部保存按钮露出来。
3. **翻译没有源/目标语言显式选择**：虽然引擎会自动识别，但用户有时候需要强制指定（比如中日混排的书自动识别不准）。

同时 Word 小工具栏参考思路让高亮颜色从 3 色扩到 6 色，为后续阅读器实时翻译按钮腾位置。

## 二、改了什么

### 1. 设置面板可拖动 / 可缩放 / 不自动消失 / Esc 关闭

**SettingsDialog.tsx**：
- 根因修复：去掉 `.modal-mask` 的 `onClick={() => onClose()}`——点主界面不再关闭。
- 新加 `.settings-float`（position: fixed）包裹层，用 inline style `transform: translate(x, y)` + `width/height` 控制位置尺寸。
- 新加 `.modal-titlebar` 作为拖动区（36px 高，浅棕背景，cursor: move），左=品牌图标+"设置"，右=关闭按钮（X）。
- 新加 `.resize-handle`（右下角 16×16，cursor: nwse-resize），pointerdown 记录原始尺寸 + 光标位置，pointermove 算 delta 改 size state。
- 拖动：titlebar `onPointerDown` → 记录 `dragOffsetRef`（dx/dy） → window `pointermove` 里更新 posRef → window `pointerup` 存 localStorage `scrollforge:settings-window-pos`。
- 缩放：resize-handle `onPointerDown` → 记录 `resizeStartRef`（w/h/px/py） → window `pointermove` 里 clamp 到 [MIN_W=640, MAX_W=1600] × [MIN_H=420, MAX_H=1100] → window `pointerup` 存 localStorage `scrollforge:settings-window-size`。
- Esc 关闭：`document.addEventListener('keydown', e => e.key === 'Escape' && !saving && onClose())`，保持和说明书一致。

**styles.css**：
- `.settings-float`：position fixed, flex column, z-index 80, overflow hidden（resize-handle 用 absolute 相对它定位）。
- `.modal-titlebar`：36px 高，#f4ead9 背景，flex row space-between。
- `.modal-titlebar__close`：24×24 圆按钮，hover 时 accent 色背景。
- `.resize-handle`：absolute right/bottom 0，16×16，cursor nwse-resize，SVG 三角描边（斜 45° 三条）。
- `.settings-modal`：flex 1 1 auto + min-height 0，宽高完全由父级 float 控制（去掉原来的固定 width/height/max-width/max-height）。

### 2. 翻译源 / 目标语言设置项

**lib/prefs.ts**：
- 加 `TranslateSource` 类型（'auto' | zh | en | ja | ko | fr | de | ru | es）和 `TranslateTarget`（同上但不含 auto）。
- Prefs 接口加 `translateSource` 和 `translateTarget` 两个字段。
- DEFAULT_PREFS 默认值 `translateSource: 'auto'` / `translateTarget: 'zh'`。
- loadPrefs 里加 TRANSLATE_SOURCES / TRANSLATE_TARGETS 常量 + pick() 兜底。

**lib/features.ts**：
- translate 功能块下新增两个 select 设置项（在 translateStyle 之后、translateUseTm 之前）：
  - 「源语言」：自动识别 / 中文 / 英文 / 日文 / 韩文 / 法文 / 德文 / 俄文 / 西班牙文
  - 「目标语言」：同上但不含 auto

### 3. 高亮颜色 3 → 6 色

**lib/annotations.ts**：
- `HIGHLIGHT_COLORS` 从 3 色扩到 6 色：黄 / 橙 / 绿 / 蓝 / 紫 / 粉（参考 Word 的高亮色板）。

## 四、踩坑

1. **CSS 里 position: fixed 被 position: relative 覆盖**：第一次写 .settings-float 时先写了 `position: fixed` 又写了 `position: relative`（本意是给 resize-handle 的 absolute 一个定位上下文），后者覆盖前者导致整个 float 变成 flow 里的 relative 元素、完全不固定在视口上。**修复**：删掉 position: relative；position: fixed 本身就是一种 positioned 上下文，absolute 定位也会相对它生效。

2. **transform: translate + overflow: hidden 的关系**：transform 改变视觉位置但不影响元素在 layout tree 里的流；overflow: hidden 会裁掉超出边界的子元素，resize-handle 因为是 absolute 相对 settings-float 定位且在它内部所以不会被裁。

3. **pointerdown / pointermove / pointerup 事件监听位置**：开始想把 move/up 挂在元素上，但拖出元素后事件就丢了；改成全部挂在 window 上、pointerdown 用 setPointerCapture 让元素即使被移除也能收到后续事件。
