# W23 · R1-UX · 阅读器实时翻译（通道 2）

> 上级索引：`../../memory/appendices/W00-工作日志索引.md`
> 分类：R1 阅读器 UX 迭代

## 一、改动原因

双通道翻译方案里的通道 2——**阅读器内实时翻译**（用户说"其实我需要的是三种人性化翻译功能……第二种是在阅读器内进行实时翻译"）。核心诉求：

1. 划词工具栏里塞「翻译一下」按钮（参考 Word 的小工具栏）。
2. 译文贴边显示，**字号和原文一样大**（和笔记小字区分开），可以多段各自展示。
3. **草稿不持久化**——关书/关软件自动消失（sessionStorage 而非 localStorage/annotations）。
4. 翻页/换位置时译文字自动跟着原句走（复用笔记已有的 `locateByText`）。

## 二、改了什么

### 1. translate.ts 扩展：支持源/目标语言显式指定

- **TranslateConfig** 加 `source: TranslateSource`（auto/zh/en/ja/ko/fr/de/ru/es）+ `target: TranslateTarget`（同上不含 auto）。
- **translateConfigFromPrefs** 把 prefs.translateSource / translateTarget 传进 TranslateConfig。
- **translateOne**：
  - 源语言：`config.source === 'auto'` 时沿用 `detectLanguage(source)`；否则直接映射到 `LanguageCode`（zh/ja/ko/en/unknown）。fr/de/ru/es 等非日韩中英统一归 `unknown`（detectLanguage 也识别不出来）。
  - 目标语言：把原来硬编码的 prompt 里"只输出简体中文译文"改成动态 `targetLabelOf(config.target)`，变成"只输出{目标语言}译文"。
- 加两个辅助函数：`languageLabelOf(code)` 和 `targetLabelOf(code)`，LANG_LABELS 映射 8 种语言标签。

### 2. AnnotationTools.tsx 大改

- **Props 扩展**：加 `prefs: Prefs`（翻译引擎配置 + 源/目标语言从这里读）。
- **新类型**：`InlineTranslation`（cfi/text/translation/index/x/y/width）+ sessionStorage 工具函数（`translateDraftKey` / `loadTranslations` / `saveTranslation` / `removeTranslation`）。
- **定位复用**：把原来 syncInline 里的贴边位置计算（rightEdge/roomRight/overflow-y）抽成 `computeInlinePos(box)`，syncInline 和新加的 `syncTranslations` 都用它；译文和笔记同位置时错开 26px。
- **新 state**：`inlineTrans`（译文字数组）、`translating`（按钮 loading 状态）。
- **新函数**：
  - `translateSelection`：调 `translateOne({ config: translateConfigFromPrefs(prefs), source: selection.text, glossary: [] })`，结果 `saveTranslation` 存 sessionStorage，`scheduleAll()` 刷新译文字，toast 显示引擎类型 + 耗时 + 草稿提示。
  - `removeInlineTranslation(cfi)`：清 sessionStorage + scheduleAll。
  - `scheduleAll`（useCallback）：同时重排笔记 syncInline 和译文 syncTranslations，替代原来内部的 schedule → syncRef.current()。
- **JSX 工具栏**：高亮色 swatches 之后、笔记按钮之前加"翻译一下"按钮（`.ann-action icon-only`，Icon name="translate"，翻译中显示 hourglass_top + disabled）。
- **JSX 贴边**：`inlineNotes.map` 之后加 `inlineTrans.map` → `.ann-translate` 容器（带 translate Icon + 译文 span + 右上 × 关闭按钮）。
- **cleanup**：useEffect 清理函数里补 `setInlineTrans([])`。

### 3. Reader.tsx

- `AnnotationTools` 调用加 `prefs={prefs}`。

### 4. styles.css

- `.ann-translate`：position fixed、贴边布局（padding 22px 右侧留空间给 × 关闭按钮）、浅蓝底色 `rgba(80,130,200,0.12)`、左侧 3px 蓝色竖条、**font-size: var(--read-font-size, 14px)**（和原文同号，区别于笔记小字）、z-index 58（低于笔记 60 但不遮挡工具条）、max 6 行溢出省略（`-webkit-line-clamp: 6`）。
- `.ann-translate__text`：译文字本体，word-break: break-word。
- `.ann-translate__close`：右上角 16×16 绝对定位按钮，hover 时加深底色和文字。

### 5. sessionStorage 键设计

- 前缀：`scrollforge:read-translate:`
- 完整：`scrollforge:read-translate:${bookKey}:${cfi}`
- 加载时扫 `sessionStorage.length` 遍匹配前缀的 key，用 cfi 反查。
- 关闭 session（浏览器/应用）自动清空 sessionStorage → 译文字消失；同一本书刷新页面也会清（符合"草稿"语义）。

- 设置面板里翻到「功能 → 翻译」：新增的「源语言」「目标语言」下拉存在（auto/zh/en/ja/ko/fr/de/ru/es × zh/en/ja/ko/fr/de/ru/es），改值后 localStorage 持久化。
- 阅读页划词 → 工具栏出现翻译按钮（在 6 色 swatches 和「写笔记」之间）；点击后 toast "已翻译（在线/本地 · Xms），关闭书本或软件后会消失"；译文贴在原文右侧（蓝色竖条 + 原文同字号）；右上 × 点了清掉 sessionStorage 条目；翻页到译文原文不在当前页时译文字消失，翻回来又出来；关闭 session 再打开 → 译文字全空（草稿清了）。

## 四、踩坑

1. **`useRef` 存 state 依赖 + useCallback 依赖不同步**：第一次写 `syncTranslations` 时依赖 `[view, bookKey]`，但它内部读了 `inlineNotesRef.current`（通过另一个 ref 桥接）。后来加了 `inlineNotesRef` 来解 syncInline 内部状态——这是 React ref 桥接状态到 useEffect 闭包的经典套路。

2. **sessionStorage 里 loadTranslations 的遍历**：`sessionStorage.getItem(key)` 之后 try JSON.parse——sessionStorage 是按 key 长度索引的，先拿到 key 再 getItem 不会双重遍历；sessionStorage 在某些 Tauri WebView2 安全策略下可能不可用（try/catch 兜底），这一点要保持。
