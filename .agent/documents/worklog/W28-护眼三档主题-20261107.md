## 1. 目标

给应用一套覆盖全局的三档视觉：日间（现状纸白）、护眼（低饱和绿纸面）、夜间（深灰纸面）。
先调研业界做法再定义色板，不允许只改主页，不允许另起状态管理。

## 2. 调研结论（详见 analysis 文档）

- 护眼不是「绿色滤镜」，而是**降蓝光 + 降色温 + 降对比 + 降亮度**的组合；纯绿高饱和反而刺眼。
- 绿色取**低饱和、中高明度**的纸面（中文圈豆沙绿 #C7EDCC / 青草绿 #E3EDCD 的降饱和版），本项目取 `#E8F0E4`。
- 夜间不用纯黑（`#000` 会在深色文字周围产生光晕），取 `#1B1D20` 纸面 + `#D0CCC6` 文字。
- 对比度：正文保持 WCAG AA 4.5:1 以上（本项目正文 10.2:1 / 10.6:1），次要文字不低于 4.5:1。
- 图片不反色；夜间仅 `brightness(0.86)` 降亮，书封（background-image）单独处理。
- 只做手动三档（顶栏循环按钮 + 设置下拉），不做跟随系统/定时：需求未要求，避免过度设计。

## 3. 做了什么

### 3.1 数据与状态（复用现有 prefs）

- `app/src/lib/prefs.ts`：`ThemeMode = 'day' | 'eye' | 'night'`；`Prefs.theme`；`DEFAULT_PREFS.theme = 'day'`；`THEMES` 白名单校验；`nextTheme()` / `themeLabel()`。
- `app/src/App.tsx`：`applyTheme(prefs.theme)` effect；持久化沿用 `scrollforge:prefs`（localStorage），重启保留。

### 3.2 CSS 令牌（`app/src/styles.css`）

- 顶部新增三套 `:root[data-theme=...]` 色板：引擎/表面/文本/描边/强调/状态/深度/3D 书架/阅读正文/EPUB 编辑页，共 ~40 个语义令牌；日间值与改造前完全一致。
- 全文件 **361+ 处**硬编码结构色收敛到令牌（旧 532 处 hex / 125 处 rgba / 34 处 white）。
- 三套色板均声明 `color-scheme`，表单控件与滚动条跟随。
- 夜间补充：`img { filter: brightness(0.86) }`、`.cover.has-art { filter: brightness(0.86) }`、书脊 `brightness(0.72) saturate(0.82)`；护眼书脊 `saturate(0.86)`。

### 3.3 阅读器正文（foliate）

- `app/src/lib/theme.ts`：`applyTheme(mode)` 写 `data-theme` 与 `color-scheme`；`applyReaderTheme(doc, mode)` 往每个章节文档 head 注入 `html/body/a/img` 规则（日间清空，保持书籍原样）。
- `app/src/components/Reader.tsx`：`themeRef` + `paintDoc` 注入 + `[prefs.theme]` effect 重刷所有已加载文档。
- **vendor 补丁**：`src/vendor/foliate-js/paginator.js` 新增 `refreshBackground()`（只按当前文档底色重刷页面四周铺底，不触发重排）。原因见 A07 §34 第 250 条。
- 修复两个实测问题：调色板读取早于根元素换档（先 `applyTheme` 再读）；分页器铺底不随 iframe 变色（调用 `refreshBackground`）。

### 3.4 界面入口

- 书架 `Shelf.tsx` 与阅读页 `Reader.tsx` 顶栏各加一个调色按钮：日间 → 护眼 → 夜间循环，`data-tip` 显示当前档位；阅读页按钮放在 `editOpen` 条件外，**EPUB 编辑页内也能切档**。
- `features.ts` 新增「外观与护眼」功能卡（设置页「功能」切面）：主题下拉 + 覆盖范围与边界说明；F1 说明书同源。

### 3.5 覆盖范围

书架（网格 / 列表 / 3D）、阅读页外壳与正文、锻造台、EPUB 编辑页（文件树 / 源码 / 段落 / 预览 / 目录 / 元数据 / epubcheck）、设置弹窗、右键菜单、toast、tooltip、下拉与滚动条。

## 5. 偏差与原因

1. **vendor 增加 `refreshBackground()`**：分页器四周铺底在章节载入时固化，换主题不跟随；其 shadowRoot 是 closed，外部改不了，只能在 vendor 加最小方法（不改渲染逻辑）。
2. **主题按钮挪出编辑条件**：原计划只放阅读页顶栏，实测进入编辑页后顶栏按钮被 `!editOpen` 隐藏，无法切档，故移到条件外。
3. **封面单独降亮**：夜间 `img{filter}` 对 `background-image` 书封无效，补 `.cover.has-art` 规则。
4. **版本号未升**：本轮为功能增补，仍为 v0.13.0；未获准升级前不动三处版本号。
