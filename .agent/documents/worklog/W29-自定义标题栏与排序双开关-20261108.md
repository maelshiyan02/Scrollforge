# W29 · 自定义标题栏与书架排序双开关（2026-11-08）

> 回指：`.agent/memory/appendices/W00-工作日志索引.md` ｜ 上次阶段：W28 护眼三档主题

## 1. 目标

1. 干掉 Windows 原生白色标题栏，把书架顶栏升级为**自定义标题栏**：左侧图标 + 标题，右侧最小化 / 最大化(还原) / 关闭，颜色随三档主题联动。
2. 消除「原生标题栏」与「应用顶栏」标题重复。
3. 书架排序从文字下拉改为**图标双开关**：三种方式（最近阅读 / 导入时间 / 书名 A-Z）循环切换 + 升序/降序切换，放到第二行视图按钮左侧。
4. 阅读页顶栏同样具备窗口按钮；窄窗口自动隐藏书名。

## 2. 实现

### 2.1 窗口与权限

- `app/src-tauri/tauri.conf.json`：`app.windows[0]` 增加 `"decorations": false`。
- `app/src-tauri/capabilities/default.json` 补 `core:window:allow-minimize / allow-toggle-maximize / allow-close / allow-is-maximized / allow-start-dragging`。
- 窗口保留 `WS_THICKFRAME`（实测 style `0x14CF0000`），边缘缩放可用；按用户确认放弃 Snap Layout 与标题栏右键菜单。

### 2.2 组件与页面

- 新增 `app/src/components/WindowControls.tsx`：三枚按钮，调 `getCurrentWindow()`；监听 `onResized` 用 `isMaximized()` 切换「最大化 / 还原」图标。
- 新增 `app/public/app-icon.png`（复制自 `src-tauri/icons/128x128.png`），标题栏左侧 24px 图标。
- `Shelf.tsx`：`.shelf-bar` 加 `titlebar` 类与 `data-tauri-drag-region`，双击空白切换最大化；品牌区改「图标 + Scrollforge + 书架」；移除原「排序」下拉，右侧接入 `WindowControls`。
- `Reader.tsx`：`.bar` 加 `titlebar` 类与拖动/双击逻辑；书名后接入 `WindowControls`。
- `styles.css`：新增 `--titlebar-h: 56px`；`.titlebar` 统一高度并 `padding-right: 0` 让窗口按钮贴边；窗口按钮 46×56、悬停 `--surface-2`、关闭悬停 `--danger`；`@media (max-width: 1100px)` 隐藏 `.bookname`。

### 2.3 排序双开关

- `prefs.ts`：新增 `ShelfSortOrder = 'asc' | 'desc'`、`Prefs.shelfSortOrder`（默认 `desc`）并纳入 `loadPrefs` 白名单校验。
- `Shelf.tsx`：状态 `order` 与 `prefs.shelfSortOrder` 同步；`cycleSort` 循环三种方式（切换到书名时自动置 asc，时间类置 desc）；`toggleOrder` 独立切换升/降；排序比较统一乘方向系数。
- UI：两个 `.btn.icon-only` 放在 `.subbar-tools` 最前（网格视图按钮左侧），图标分别为 `schedule` / `file_download` / `sort_by_alpha` 与 `arrow_upward` / `arrow_downward`，中文提示走 `data-tip`，`aria-label` 固定为「切换排序方式 / 切换排序方向」。

## 4. 偏差与风险

- 无原生标题栏后，Windows 11「悬停最大化按钮弹出贴靠布局」与标题栏右键系统菜单不再可用；用户已确认不需要。
- 窗口边缘缩放依赖 `WS_THICKFRAME`，本轮只验证样式标志与尺寸变化，未逐边手工拖拽；如实测异常，后续补 `startResizeDragging` 透明手柄。
- 阅读页在 820px 最小宽度下仍有较多按钮，当前通过隐藏书名避免溢出；未做按钮收纳/溢出菜单。
