## 3. C：三档收敛（完成）

- 阅读 / 编辑 / 锻造共用同一个 Reader 外壳：唯一顶栏（`PageBar` 风格 + 三档切换）、唯一底栏、视图标签、快捷键、脏改动确认。
- 锻造草稿与编辑写回路径彼此独立：锻造只写 `book_dir/<id>/forge-draft.json` 的 `target`，原文与 EPUB 源不被译文覆盖。

## 4. D：编辑创作能力（本轮落地）

**Rust（`epub_edit.rs` / `main.rs`）**
- 新增 `InsertEdit { index, tag, inner }`：在第 index 段之后插入新块。
- 抽出 `apply_block_edits_ex(raw, edits, inserts)`：与原有逻辑同一套「从后往前拼接 + 区间重叠校验 + `validate_xml`」，插入片段按所在行的缩进与换行风格（`\n` / `\r\n`）生成，同锚点多次插入按请求顺序拼接。
- `write_blocks_with_inserts` + `BlockWriteResult.inserted`；`edit_write_blocks` 增加可选 `inserts` 参数（`Option<Vec<InsertEdit>>`，默认空）。
- 旧函数 `apply_block_edits` / `write_blocks` 收窄为 `#[cfg(test)]`，避免生产死代码警告。
- 新增单测 `insert_blocks_after_anchor_keeps_other_bytes`：插入 2 块后总块数 +2、原块字节全部保留、缩进匹配。

**前端（`EpubEditPanel.tsx`）**
- 新建块：`inserts[anchor]` 列表（段落 / H1–H3 / 空行 `<p><br/></p>`），在预览里以 `.blk.is-new` 追加并可输入；「应用改动」时随 `inserts` 一起提交。
- 上移 / 下移：交换相邻两段的内容与标签，原块的 class/id 留在原位（已在说明书与本文档标注该取舍）。
- 下划线：`execCommand('underline')`，`inline-format.ts` 白名单加 `u`。
- 插入图片：从 EPUB 现有图片资源里挑选，按当前文件计算相对路径后 `insertHTML`，避免 `javascript:`/跨目录非法引用。
- 内容受控问题：新建块的真实内容存 `insertHtmlRef`（按 id），React 只渲染创建时快照，避免每次输入重设 `innerHTML` 导致光标跳到开头。

## 5. E：润色与撤销（本轮落地）

- **整段撤销 / 重做（段落视图）**：`BlockSnapshot`（预览行、删除集、`blockEdits`、新建块）在改动前压入 `undo`，撤销时压入 `redo`；按钮 + `Ctrl+Z` / `Ctrl+Shift+Z`（面板 `onKeyDown` 截获，避免 contenteditable 原生撤销抢事件）；打字按 1.2s 合并；写回成功后清空历史（块坐标已变）。
- **译文框撤销（锻造）**：按段落 key 维护 `undo` 栈，`Ctrl+Z` 撤销本段译文；AI 翻译 / 润色结果同样入栈。
- **AI 润色**：`translate.ts` 新增 `polishOne({config, text, source})`，复用在线/本地 LLM（提示词强调「只改表达、不改原意、占位符原样保留」）；内置 NLLB 只做翻译，会明确报错要求切 LLM；结果只写锻造草稿 `target`，由人工确认后保存。
