# W31 · 第三轮反馈：菜单对齐 / 设置与说明书漏缝 / 说明书详细化（2026-11-09）

> 阶段：R6-UX 收尾（反馈 1–3）
> 产物：`build/Scrollforge.exe`（32,510,976 字节，14:15:18，与 `DirectML.dll` 18,527,776 字节同目录）
> 方案文档：`../../../../.trae/documents/设置页与三档合一v2方案.md`

## 1. 背景

用户第三次反馈 3 条：

1. 主页左下角菜单文字仍未左对齐（上一轮只修了「关于 Scrollforge」双行），文字错位且显示不完整，要求文字向图标左对齐。
2. 设置详细页的搜索栏与底部「取消/保存」栏缺乏图层拦截，上下会漏缝（内容从缝隙透出）。
3. 说明书同样漏缝、左右没有铺满；内容过于简略；快捷键要分场景说明；给主要功能补快捷键；说明书页 Esc 无法返回主页。

## 2. 逐条处理

### 2.1 菜单文字左对齐（问题 1）

- 根因：`.app-menu__item` 是 flex 行，`span { flex:1 }` 只是把文字拉满，文字仍在按钮内居中；再加 `justify-content` 也无法让图标列固定。
- 改法：改 **CSS Grid 三列** `18px minmax(0,1fr) auto`，`column-gap:10px`，`justify-items:start`：
  - 第一列固定 18px 放 Material 图标（`> .mi` 单独 `justify-self:start`）；
  - 第二列 `> span:not(.mi)` 占满剩余宽度并 `text-align:left`，加 `min-width:0 / nowrap / ellipsis` 防截断变形；
  - 第三列 `em / kbd` 统一 `justify-self:end`（语言、版本、快捷键靠右）。
- 弹层宽度 232 → **260px**，`关于 Scrollforge` 不再被省略号截断。
- 同时删掉上一轮遗留的 flex 版本重复规则，只保留一套 grid 定义。

### 2.2 设置页「漏缝」（问题 2）

- 根因不是 z-index，而是 **sticky 元素宽度只有内容盒** + **滚动容器的 padding 区域内容可穿透**：
  - 搜索栏 `.settings-search` 只有内容宽度，左右各留 24px 透光条；
  - 底部 `.settings-actions` 同样只占内容宽，左右各留 24px；
  - 容器 `padding-top:20px` 时，滚动内容会从搜索栏上方的 20px 条带透出（CDP 滚动截图已复现）。
- 改法：
  - `.settings-main` 顶部 padding 归零（`padding:0 24px 0`），呼吸位改由 `> h2 { margin-top:20px }` / `.settings-search + h2 { margin-top:6px }` 提供；
  - 搜索栏与操作条 `margin:0 -24px`（底栏 `auto -24px 0`）**负边距铺满整宽**，去圆角、实底 `var(--surface)`、保留分隔线与轻阴影；
  - 底栏 `padding:12px 24px`，`position:sticky; bottom:0; z-index:2`，与容器底边齐平，底部不再留 12px 条带。

### 2.3 说明书漏缝 + 全宽 + 详细化（问题 3）

- 全宽：删掉 `.help-page__body { max-width:920px; margin:0 auto }`，改 `max-width:none; width:auto; margin:0; padding:0 28px 28px`；sticky 搜索栏 `margin:0 -28px` 铺满左右；正文从大纲右侧一直顶到窗口右边缘。
- 漏缝：搜索栏去圆角、实底、`border-bottom` 分隔；容器顶部无 padding，sticky 贴住滚动口顶边，不再透内容。
- 详细化：`HelpDialog` 重写为 9 个章节 —— 快速上手 / 三档模式 / 快捷键（按场景）/ 阅读操作详解 / 编辑操作详解 / 锻造翻译详解 / 设置与存储 / 常见问题 / 功能清单；左大纲 10 项可点击跳转，顶部搜索同时过滤快捷键与功能卡。
- 排版：说明文字去掉反引号，全部改 `<kbd>` 标签；导航图标统一为功能清单同一套语义（`auto_stories / edit_note / build / translate / tune`），长文案加省略号。
- 清理：删除旧 F1 弹窗（`.help-modal / .help-head / .help-body / .help-actions`）与旧的 `.help-page__bar / __icon / __title / __hint` 重复样式，避免与新整页规则互相覆盖。

### 2.4 快捷键分场景 + 新增功能键（问题 3）

- `features.ts`：`SHORTCUTS` 增加 `scope` 字段，新增 `ShortcutScope` 与 `SHORTCUT_SCOPE_LABEL`：
  - `universal` 通用（任何页面）：Esc、F1、Ctrl+,、滚轮 / ↑↓、Ctrl+Z、Ctrl+Shift+Z；
  - `shelf` 书架主页：滚轮 / ↑↓、单击书籍、拖拽文件；
  - `reading` 阅读：← / PageUp、→ / PageDown / 空格、Ctrl+←/→、↑↓、T、E、G、Ctrl+滚轮、全屏看图 ←/→、单击图片、Esc；
  - `editing` 编辑：Ctrl+Z、Ctrl+Shift+Z、Ctrl+U、Ctrl+滚轮、Esc；
  - `forge` 锻造：Ctrl+Z、Esc。
- 设置页「快捷键」与说明书同源，按场景分表渲染（`SCOPE_ORDER` + `SHORTCUT_SCOPE_LABEL`）。
- **新增实际绑定**（`Reader.tsx`，阅读档字母键，输入框/弹层打开时不抢键）：
  - `T` 展开 / 收起目录；
  - `E` 进编辑（EPUB 直进，其它格式先建工作副本）；
  - `G` 进锻造（未解析章节时中文提示）。

### 2.5 说明书页 Esc 无法返回（问题 3）

- 根因：App 从未监听 Esc；说明书是整页覆盖层，Reader 的 Esc 监听被语义挡在后面。
- 改法：App 在 `window` 上以 **捕获阶段** 监听 keydown：
  - `helpOpen || settingsOpen` 时 Esc `preventDefault + stopPropagation`，先关 help 再关 settings；
  - 返回给打开它之前的页面（从书架 F1 打开即回主页，从阅读页打开则回阅读页），文案同步改为「Esc 关闭说明书」；
  - F1 任意页面开关说明书、`Ctrl+,` 打开设置保持原样。

## 4. 坑与规则（同步 A07 §38）

- sticky 元素「漏缝」多数是宽度不匹配 + 容器 padding：负边距铺满 + 顶部 padding 归零 + 呼吸位交给标题。
- CSS Grid 三列是菜单「图标列固定 + 文字左对齐 + 尾列右贴边」的最稳解法，flex + `flex:1` 做不到。
- 整页覆盖层的 Esc 必须在 App 层用捕获阶段拦截，否则会与阅读页的 Esc 退出书冲突。
- 非 DPI 感知进程的 PrintWindow 只截到窗口左上角一部分（2560×1440 @125% 下抓 1000×690 会切掉底栏），验收优先 CDP 截图。
