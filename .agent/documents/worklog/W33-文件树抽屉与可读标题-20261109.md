## 一、目标

S1 修好高度链后，文件树仍有两个结构问题：

1. 展开文件树会挤压编辑区宽度，段落/源码视图在窄窗口下变形；
2. 树里只有 `title.xhtml / color01.xhtml / ch_115048.xhtml` 这类文件名，看不出是「第一章 / 后记」。

本阶段把文件树改成**不占编辑器宽度的覆盖式抽屉**，并给正文文件补上**可读标题**（TOC `href → label` 映射，缺省回退文件名）。

## 二、改动（3 个文件）

### 1. `app/src/styles.css`

`.edit-panel__body` 增加 `position: relative` 作为抽屉定位基准；`.edit-panel__tree` 由占位侧栏改为覆盖式抽屉：

- `position:absolute; top:0; bottom:0; left:0; width:280px; z-index:20`
- `overflow-y:auto; overflow-x:hidden; overscroll-behavior:contain`
- `background: var(--surface)` + 右描边 + `box-shadow: 8px 0 24px`，不再参与 flex 宽度分配
- 新增 `.edit-panel__veil`：`absolute; inset:0; z-index:19` 半透明遮罩，点击收树
- 新增 `.edit-panel__tree-head`：`sticky; top:0` 的树头（标题 + 收起按钮），滚动时始终可见
- 新增 `.edit-panel__tree li.is-chapter` 两行式条目：主行可读标题 `nowrap + ellipsis`，副行文件名 + 大小（10px、`font-variant-numeric: tabular-nums`）

### 2. `app/src/components/EpubEditPanel.tsx`

- 删除原 `visibleGroups`，改为两个派生列表：
  - `visibleEntries`：`blocks` 切面只保留 `text`/`toc`，其余切面全部保留（沿用原行为）；
  - `chapterList`：按 nav `tree` 深度优先展开，用既有 `findEntryByHref` 把 `href` 对到正文文件，`href → label` 生成 `{ entry, label }`；未被目录覆盖的正文文件按原顺序补在末尾（`label: ''`，渲染时回退 `baseName()`）。
  - `structuralGroups`：`groupByRole(visibleEntries.filter(role !== 'text'))`，封面/彩页/样式/图片/字体/manifest 仍按角色分组。
- 文件树 JSX 重写：遮罩 + `aside.edit-panel__tree` + sticky 树头；正文分组标题为「正文文件（N）」，条目两行（可读标题 / 文件名 · 大小），其余分组沿用原单行条目。
- 收起入口三处：树头 close 按钮、遮罩点击、Esc（见下）。

### 3. `app/src/components/Reader.tsx`

Esc 语义调整：编辑档且 `editToolbarRef.current?.treeOpen` 为真时，第一次 Esc 只收抽屉并 `return`，再按一次才回阅读档（仍保留 dirty 确认）。

## 三、验收（CDP，临时 9222，验证包 15:30:40）

- 抽屉定位：`.edit-panel__tree` 计算 `position: absolute`，宽 280px；树 `clientHeight 705 / scrollHeight 743`，滚轮 `scrollTop 23.2` 生效。
- 不挤压编辑区：开树前后编辑内容区宽度都是 1200px（窗口宽），段落/源码视图不再变形。
- 可读标题：正文条目显示两行，例如「彩页 1 / color01.xhtml · 404 B」「第一章 / ch_115048.xhtml · 40.4 KB」；分组计数「正文文件（14）」「目录（1）」（验证包文案为旧版「正文章节（14）」，正式包已改为「正文文件」）。
- Esc：第一次只收树，`edit-panel` 仍在（未退回阅读档）；再按一次才回阅读。遮罩点击同样只收树。
- 滚动与视觉：无横向滚动条（`overflow-x:hidden` 修复），sticky 树头滚动时保持可见。截图 `.agent/tmp/shot-11-s2-tree.png`、`.agent/tmp/shot-12-s2-tree-final.png`。

## 四、坑（已写入 A07 §40）

1. **同一节点上的多个 `window` keydown 监听无法用 `stopPropagation` 互相阻断**：`EpubEditPanel` 后注册的 Esc 监听拦不住 `Reader` 先注册的监听，Esc 被当成「回阅读档」。改为在 `Reader` 的 Esc 分支里判断 `treeOpen` 先收树。
2. **`overflow-y:auto` 隐含 `overflow-x:auto`**：只写纵向滚动时，抽屉底部出现横向滚动条；补 `overflow-x:hidden`。
3. **抽屉浮层必须有独立定位基准**：`.edit-panel__body` 缺 `position:relative` 时，`absolute` 抽屉会以 `.edit-panel` 为包含块，盖住顶栏。
