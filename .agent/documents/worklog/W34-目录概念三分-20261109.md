## 一、目标

把三个「目录」概念拆开，避免阅读档与编辑档看起来在做同一件事：

| 场景 | 概念 | 内容 |
| --- | --- | --- |
| 阅读档顶栏抽屉 | **章节列表** | 只显示正文章节，点击跳转 |
| 编辑档文件树（S2） | **文件列表** | 全文件，正文文件带 TOC 可读标题 |
| 编辑档「目录结构」切面 | **目录结构** | 真正编辑 nav.xhtml / toc.ncx / spine 顺序 |

## 二、改动

### 1. `app/src/components/Reader.tsx`

- 新增 `PLATE_PAGE_RE` 与 `isChapterHref()`：在 `FRONT_PAGE_RE`（封面/书名页/简介/目录页）之外，再排除 `color/plate/illustration/彩页` 命名的彩页与插图页。
- 新增 `chapterToc = toc.filter(...)`：只用于阅读档抽屉展示；章节上/下翻页、进度定位仍使用完整 `toc`，避免改变既有导航语义。
- 阅读档抽屉文案：
  - 顶栏按钮 `data-tip="展开章节列表（仅正文章节，点击跳转）"`、`aria-label="章节列表"`；
  - 抽屉标题「章节列表」+ 计数「N 节」，空态「这本书没有正文章节信息」；
  - 遮罩/关闭按钮文案同步为「收起章节列表」。
- 编辑档第四切面由「目录」改名「目录结构」（`EDIT_TABS` 标签、编辑模式按钮提示同步）。

### 2. `app/src/components/EpubEditPanel.tsx`

- 内嵌模式下隐藏的面板切面按钮 `目录` → `目录结构`，并补 `data-tip="目录结构：编辑 nav.xhtml / toc.ncx 与 spine 顺序"`。
- 目录结构工具栏新增「打开对应文件」按钮（`open_in_new`）：
  - 仅在单选且该项有 `href` 时可用；
  - 点击后用 `findEntryByHref(entries, node.href)` 找到目标文件，复用 `handleSelect()`（含 dirty 确认），成功后切到「段落视图」。
- 目录结构本身仍保留全部条目（含彩页），拖拽排序、批量上下移、设置目标、重命名目标文件逻辑未动。
