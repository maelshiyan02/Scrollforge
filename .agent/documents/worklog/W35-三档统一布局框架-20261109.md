## 一、目标

把三档（阅读 / 编辑 / 锻造）收敛到同一套外壳与同一套浮层、滚动规则，为后续「文件级新建/重命名/删除/移动（同步 OPF manifest/spine）」和「阅读层划词撤销栈」提供稳定的布局前提。

结构契约：**唯一顶栏 → 舞台（stage）→ 按档位底栏**。

浮层契约：章节列表 / 排版 / 脚注 / 彩页 / 锻造 / 文件树一律 `absolute` 定位于 stage 内，贴边定位，不参与 flex 宽度分配，互不挤压。全屏模态与可拖动二级弹窗（settings / help / gallery-viewer / toc-picker）保持 `fixed`，属于窗口级而非舞台级。

滚动容器契约：

```
父容器：display:flex; flex-direction:column; min-height:0
滚动子容器：flex:1; min-height:0; overflow-y:auto; overflow-x:hidden;
           overscroll-behavior:contain; scrollbar-gutter:stable
```

## 二、改动（仅 `app/src/styles.css`）

- `.stage`：保留 `position:relative; flex:1; min-height:0`，新增 `overflow:hidden`，兜住所有 absolute 浮层，禁止越出舞台压到底栏；上方补契约注释块。
- `.toc-list`（阅读章节列表）：`flex:1` 之外补 `min-height:0`、`overflow-y:auto`、`overflow-x:hidden`、`overscroll-behavior:contain`、`scrollbar-gutter:stable`。
- `.forge-body`（锻造档）：由 `overflow:auto` 改为 `overflow-y:auto; overflow-x:hidden`，补 `overscroll-behavior:contain; scrollbar-gutter:stable`。
- `.gallery-grid`（彩页抽屉）：同上，补齐纵向滚动契约。
- `.edit-panel__tree`（编辑文件树）：在既有 `overflow-y:auto; overflow-x:hidden; overscroll-behavior:contain` 基础上补 `scrollbar-gutter:stable`。

未改动 DOM 结构：`Reader.tsx` 已是「顶栏 → `main.stage` → 底栏」，浮层都是 stage 子节点；`EpubEditPanel` 已是 `.edit-panel`（absolute inset 0）+ `.edit-panel__body`（relative）容器。
