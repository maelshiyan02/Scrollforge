## 一、目标

把原来的「段落视图 / 源码视图」两个切面合并成一个 **段落视图**，内部提供三态：

| 态 | 说明 |
| --- | --- |
| 富文本 `rich` | 默认；按块渲染可编辑正文 |
| 源码 `source` | 单栏原始 XHTML/XML/CSS 文本 |
| 分屏对照 `split` | 左富文本、右源码，两栏同步滚动、光标互相定位、改动实时镜像 |

顶栏的「源码视图」切面按钮移除；切换按钮落到段落视图第二行右侧，用三个图标（`article` / `code` / `vertical_split`）表示。

## 二、改动

### 2.1 `app/src/components/EpubEditPanel.tsx`

- `EditTab` 由 `'source' | 'blocks' | 'meta' | 'toc'` 收窄为 `'blocks' | 'meta' | 'toc'`；新增导出类型 `BlockView`。
- `splitOpen: boolean` → `blockView: BlockView`（默认 `rich`）；`blockable = blocks.length > 0` 为假时（css / opf / ncx 等非正文）强制 `source`，富文本与分屏按钮置灰。
- `tabButtons` 删除「源码」；`tab === 'blocks' || tab === 'source'` 收敛为仅 `blocks`；原非 blocks 分支的源码框删除。
- 后端 `edit_scan_blocks` 的块区间改存 `blockSpansRef`。**注意：Rust 给的是 UTF-8 字节偏移**，新增 `toCharSpans()` 一次性映射成 JS 字符串下标（含 4 字节码点），否则中文正文切分会错位。
- 新增 `composeBlockDraft()`：按 `restorePreview → normalizeBlockBreaks → sanitizeInline` 同一套写回规则，把改过的段、删除的段、新建的段、被改标签的段合成到源码文本上；输出附加 `toDraft / toBase` 偏移换算。
- 分屏镜像：`MutationObserver` 监听 `.block-page`（打字 / 加粗 / 粘贴 / 翻译 / 删除 / 改标签），停顿 180ms 合成一次，写入 `mirrorText`（只预览，不落盘）；无改动时回到原文，避免整章重渲染。
- 富文本 → 源码光标：点中某段时，用 `toDraft(innerStart)` 定位源码光标并按行号估算滚动。
- 源码 → 富文本光标：`onSelect / onClick / onKeyUp` 用 `toBase(selectionStart)` 反算原文偏移，命中段落加 `.is-src-active` 并平滑滚到可见处；落在段间空白时归到前一个块。
- 双向滚动：按 `scrollTop / (scrollHeight - clientHeight)` 比例联动，`scrollLockRef` 做 60–160ms 短锁防互相拉扯；进入分屏时先对齐一次。
- 源码框字号跟随 `blockFont`（非正文文件用 `srcFont`），分屏行高 1.9；Ctrl+滚轮在正文源码框调的是 `blockFont`，保证两侧字号一致。
- 键盘：源码框内的 Ctrl+Z 交还浏览器原生撤销，不再被段落级撤销栈接管。

### 2.2 `app/src/components/Reader.tsx`

- `EDIT_TABS` 删除「源码视图」；顶栏提示改为「段落（富文本 / 源码 / 分屏对照）/ 元数据 / 目录结构」。

### 2.3 `app/src/styles.css`

- 富文本页宽 720 → 820；分屏下 `.block-page` 取消限宽、左右内边距收紧到 30px。
- 新增 `.block-view.view-source .block-source { flex:1 1 100% }`、`.block-viewsw`（三态按钮组）、`.blk.is-src-active`（源码光标对应段的虚线高亮）。
- `.block-bar` 改为 `flex-wrap: wrap` + `gap: 6px 10px`：836 窄窗时按钮换行而不是被裁掉。

## 五、已知边界与后续

- 分屏镜像只用于「对照预览」，不写盘；点「应用改动」才走 `edit_write_blocks` 落盘。
- 源码框手动改字且富文本有未应用改动时，仍按原规则标 `blocksStale`（提示先刷新预览），不做隐式合并。
- 富文本里渲染阅读高亮 / 下划线 / 划词译文（S8 计划里的第二项）不在本轮：它依赖 S6 把标注从 localStorage 落到 `阅读壳/` 并带锚点，届时再接编辑档只读/可编辑渲染。
- 源码模式删字会连带删标注、且无法在源码模式补回标注——仍按 S6 的 `partial / orphan` 降级策略处理。
- 新建块目前只在富文本与镜像里生效，标签名/属性以外的结构级改动需「应用改动」后回读。
