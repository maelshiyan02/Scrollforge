## 一、目标

把书库从「根目录摊一堆书 + 若干 `flat_<hash>` 工作目录」迁到可读的
`<书名>__<短编号>/`，同时生成 `library-index.json`，让：

- 资源管理器里直接看出是哪本书；
- 进度、修订、锻造草稿、阅读壳不因改名失联；
- 索引缺失/损坏可自动重建，单本异常不影响其他书；
- 设置页能手动跑一次书库自检。

## 二、改动

### 2.1 Rust（`app/src-tauri/src/main.rs`）

- `BookMeta` 新增 `dirname`（camelCase `dirName`）与 `sourceFingerprint`。
- `book_dir(id)` 改为 `resolve_book_dir`：索引登记目录 → 扫各目录 `meta.json` → 退回旧式 `<root>/<id>`；原有约 15 处调用点自动受益。
- 新增命名与迁移工具：
  - `dir_name_for(title, id)`：清洗 Windows 非法字符 `\ / : * ? " < > |`，去尾部空格与点，截断 40 字，追加 `id` 的 6 位短编号；空标题回落「未命名」。
  - `unique_book_dir`：同 id 目录复用，同书名冲突追加 `-2/-3`，迁移可重复执行。
  - `resolve_book_dir` / `read_book_meta` / `write_book_meta` / `source_in_dir` / `move_path` / `merge_work_dir`。
- `migrate_library_layout(app)`（启动 `setup` 调用，错误不阻塞启动）：
  1. 根目录散装正文 → 建 `<书名>__<短编号>/`，`fs::rename` 为 `source.<ext>`，写 `meta.json`（保留原 id / 标题 / 来源文件名 / 格式 / 大小 / 导入时间 / 缓存封面）。
  2. 已有书目录名不规范 → 改名为目标名并回写 `dirName`。
  3. 遗留工作目录（有 `meta.json` 却没有正文，通常是文件改名前生成的 `flat_<hash>`）按 `sourceName` 并入同名书目录后删除。
- `library-index.json`：
  - 结构 `{ schemaVersion:1, updatedAt, books:[{ id, dirName, title, sourceName, sourceFingerprint, sidecar, translation, lastCheckedAt }] }`。
  - 缺失/损坏 → 空索引，不阻塞阅读；启动时若迁移过或索引缺失则重建写回。
  - 原子写：临时文件 + rename。
- 新命令 `library_check`：先迁移，再核对正文缺失、目录未登记、id 重复、正文与上次检查不一致，重建索引并返回报告。
- `import_library` 直接落可读目录，写 `source.<ext>` 与导入时指纹，并同步索引。
- 封面统一：书库与历史模式都按「书名.ext」写入 `covers/`（历史模式仍用 `cover.ext`），书目录有 `meta.json` 时回写 `cover` 字段。
- `shelf_health` 正文存在性改走 `book_source_path`，迁移后的目录书也能参与封面修复。

说明：指纹用流式 FNV-1a 64 + 字节数（`fnv1a:<len>:<hex>`），不引入 sha2 依赖；`library_check` 每次把最新指纹写回索引，用于「与上次检查相比是否变化」。

### 2.2 前端

## 五、已知边界与后续

- 迁移只认能解析的正文扩展名；根目录里无法识别的散文件不会被搬动。
- 遗留工作目录若找不到同 `sourceName` 的正文，会原样保留（不进书架、不进索引）；需要人工判断。
- 迁移本身无回滚 UI；验证前已对书库做过整目录备份，确认后删除。
- 运行时往书库根目录丢文件不会立即迁移，需重启或点「检查书库」。
