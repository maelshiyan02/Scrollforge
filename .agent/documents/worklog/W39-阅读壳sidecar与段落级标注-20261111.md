# W39 — 阅读壳 sidecar 化与段落级标注模型

日期：2026-11-11
状态：已完成并出包
关联计划：`../plans/04-三档数据分层与双文档架构-20261111.md`（S6）
上一阶段：`W38-书库改名后编辑路径回归修复-20261111.md`（S5 回归修复）

## 一、目标

把阅读档产生的数据从 localStorage 搬到书目录内，做到「跟着书走」：

1. 高亮 / 笔记 / 划词译文写进 `<书目录>/阅读壳/`，与母本同层，复制或移动整个书目录即可带走；
2. 壳文件名固定，不随书名变化（避免重演 W38「改名后路径失效」）；
3. 标注从「一段字符串 + CFI」升级为「段落块锚点」，原文改动后能判断 `partial` / `orphan`；
4. 索引与自检能长期盯着壳文件，命名漂移或残留旧文件要能被发现。

## 二、壳文件与目录契约

```
<书库根>/<书名>__<短编号>/
├── source.epub                  # 母本（L0，只读）
├── meta.json
├── forge-draft.json
├── 阅读壳/                       # L1 阅读壳
│   ├── manifest.json            # schemaVersion/bookId/书名/母本名/指纹/大小/mtime/各文件时间戳
│   ├── annotations.json         # 高亮与笔记（含锚点）
│   └── translate-drafts.json    # 划词译文草稿
└── forge_edit/                  # L2 锻造工作副本
```

- 固定名 + 白名单 `["annotations", "translate-drafts", "reading"]`，同时挡住路径穿越与命名漂移。
- `manifest.json` 里 `sourceFingerprint` 复用「母本 size + mtime 未变」的旧值，写一次标注不全量重读 EPUB。

## 三、后端（`app/src-tauri/src/main.rs`）

新增「S6：阅读壳」段（插在 `ScanItem` 之前）：

- `atomic_write_text`：先写 `.json.tmp` 再 `fs::rename`，崩溃不留半截 JSON。
- `refresh_sidecar_manifest`：补母本指纹、大小、mtime，扫描白名单文件写入字节数与时间戳。
- `stamped_sidecar_json`：写盘前给内容盖 `schemaVersion` / `bookId` / `sourceFingerprint` / `updatedAt`。
- `read_sidecar` / `write_sidecar` / `sidecar_info` 三条命令；读写都经 `book_dir`（唯一路径来源）。
- `read_sidecar` 在新路径缺失时会顺手把书根的旧壳文件迁入并删旧（升级后第一次打开书不丢标注）。
- `adopt_legacy_sidecars`：迁移与自检时批量收养书根旧壳文件；`migrate_library_layout` 末尾新增步骤 ④ 调用它（不计入 `changed`）。
- 删除旧命令 `read_translate_drafts` / `write_translate_drafts`（已由通用壳命令取代）。
- `library_check`：开头先 `adopt_legacy_sidecars`，循环内对每本有壳目录的书 `refresh_sidecar_manifest`，并收集书根遗留壳文件与 `阅读壳/` 白名单外文件；`LibraryReport` 新增 `sidecars_moved` / `legacy_sidecars` / `unknown_sidecars`。
- 索引与自检的 `sidecar` 字段改为 `has_sidecar_data(&dir)`（原来只认书根的 `translate-drafts.json`）。

## 四、前端

### `app/src/lib/annotations.ts`（重写）

- 类型：`AnchorState = 'ok' | 'partial' | 'orphan'`、`AnnotationAnchor { href, blockIndex, textHash, blockText, range, state }`；`Annotation` 保留 `value`（CFI）与 `noteOffset`，新增 `anchor`。
- 导出 `normalizeText` / `hashText`（FNV-1a 32）/ `anchorRange`。
- `loadBookAnnotations` → 走 `read_sidecar`，返回 `{ list, existed }`；读取时先去掉 BOM 再 parse。
- `saveBookAnnotations` → `write_sidecar`，payload `{ schemaVersion: 1, annotations }`。
- `readLegacyAnnotations` / `clearLegacyAnnotations`：localStorage 旧标注一次性迁移。

### `app/src/components/AnnotationTools.tsx`

- `persist` 改写壳文件；失败 `onNotify("标注保存失败：…")`。
- 新增 `syncAnchors(doc, index)`：
  - 有锚点：块缺失 → `orphan`；`hashText(normalizeText(block.textContent))` 与 `anchor.textHash` 不符 → `partial`，并按新文本裁剪 `range`；
  - 无锚点 / 孤儿：`el.resolveNavigation(cfi)` → `anchor(doc)` 得 Range，用 `anchorRange` 补全 `{ href, blockIndex, textHash, blockText, range, state: 'ok' }`。
- `onLoad` 与 `applyLoaded` 都会校验一次；`applyLoaded` 改为重新 `renderer.getContents()`（异步读壳时挂载期 contents 可能为空）。
- 锚点提示延迟 1400ms 发出，避免被单例 toast 的「已回到上次位置」覆盖。
- 划词新建高亮 / 笔记都带上 `anchor`；笔记目标类型增加 `anchor`。

### `app/src/lib/translate-drafts.ts`

- 改走 `read_sidecar` / `write_sidecar`（`translate-drafts`）。

### `app/src/components/SettingsDialog.tsx`

- 自检统计纳入 `sidecarsMoved` / `legacySidecars` / `unknownSidecars`；统计行显示「迁入阅读壳 N」，异常列表增加「旧壳文件未迁入」「未识别的壳文件」。
- 新增「阅读数据存在哪」说明块：壳文件固定名、随书目录搬、清缓存不丢、锻造译文仍在 `forge-draft.json`。

## 六、偏差与注意

- 壳文件名按拍板改为固定名（计划早期写的是 `<书名>.标注.json`），避免书名变动牵连文件名。
