# W40 — 阅读撤销栈与标注面板

日期：2026-11-11
状态：已完成并出包
关联计划：`../plans/04-三档数据分层与双文档架构-20261111.md`（S7）

## 一、目标

让阅读档的标注操作可回退、可总览：

1. 高亮、笔记、划词译文的增 / 改 / 删都能撤销与重做，连续操作逐步回退；
2. 撤销历史跟随书目录落盘，重启应用后最近 N 步仍可撤销；
3. 标注面板按章列出全部高亮 / 笔记 / 划词译文，支持跳转、编辑笔记、删除，并标出 `partial` / `orphan`；
4. 面板入口放在阅读档顶栏，不改动三档既有布局。

## 二、撤销栈设计

新增 `app/src/lib/undo-stack.ts`：

- 记录粒度：`{ id, kind, target, label, at, before, after }`，`kind` 为 `annotations | drafts`；
- 快照而非 diff：`before/after` 保存整份标注列表或译文草稿表，删除、改写、重做都能原样还原；
- 容量：内存 40 步，落盘最近 20 步；
- 合并窗口：`mergeWindow` 可配（默认 0，阅读层不合并，保证「连续改译文逐步回退」）；
- 持久化：写 `<书目录>/阅读壳/history.json`，格式
  `{ version: 1, entries: [...], updatedAt }`，250ms 防抖，撤销/重做后同步刷新；
- 无 `bookId` 的临时书只在内存中生效。

后端 `main.rs` 的壳文件白名单扩为 4 个固定名：

```rust
fn sidecar_file_names() -> [&'static str; 4] {
    ["annotations", "translate-drafts", "reading", "history"]
}
```

因此 `manifest.json` 统计、旧壳收养、`library_check` 的未知壳检测自动覆盖 `history.json`，无需新命令。

## 三、接入点

`AnnotationTools.tsx`：

- 新增 `commitAnnotations` / `commitDrafts` 两个统一入口，先写壳 / 更新 store，再压入撤销栈；
- 接入操作：添加高亮、删除标注、添加 / 修改 / 删除笔记、添加 / 重新翻译 / 删除划词译文；
- 拖动小字和自动锚点修复只写盘、不记历史，避免撤销栈被位置类变更灌满；
- `Ctrl+Z` 撤销、`Ctrl+Shift+Z` / `Ctrl+Y` 重做；输入区（`INPUT/TEXTAREA/SELECT/contentEditable`）让给原生撤销；
- 阅读正文在 closed shadow root 的 iframe 内，按键不冒泡到窗口，故在 `attachDocument` 里对每个文档再挂一份 keydown；
- 撤销标注时同步调用 `deleteAnnotation` / `addAnnotation`，保证磁盘与页面覆盖层一致；
- 撤销译文时用新增的 `replaceDrafts(bookId, table)` 整表恢复并触发重排。

## 四、标注面板

- 入口：阅读档顶栏章节列表按钮旁新增「标注面板」按钮，通过 `window` 事件 `scrollforge:annotation-panel` 切换，避免面板状态上提到 `Reader`；
- 位置：右侧抽屉 `.ann-panel`（340px，独立滚动，滚轮不带动正文）；
- 分组：按 `index` 分章，章标题优先取 `book.toc`，TOC 未就绪时回退文件名 / 「第 N 节」，章节加载完成后自动刷新；
- 条目：高亮 / 笔记显示原文与笔记摘要，划词译文显示译文 + 原文；`partial` 标「部分失效」，`orphan` 标「原文已删除」；
- 操作：点击条目跳转（`goTo`，跳转后收起面板）、编辑笔记（打开笔记卡）、删除（写入撤销栈，可 Ctrl+Z 恢复）；
- `Esc` 优先收面板 / 笔记卡 / 工具条，再交给阅读页。

## 五、CDP 实测

测试书：`（中译）我假孕了，但丈夫回来了（样章·忠实版）__c21b50`（原先没有 `阅读壳/`，测试后整目录删除）。

1. **删除高亮可撤销**：选中正文 → 黄色高亮（`annotations.json` 1 条）→ 面板删除（0 条）→ `Ctrl+Z` 恢复为 1 条，toast「已撤销：删除标注」；`Ctrl+Shift+Z` 再删除、`Ctrl+Z` 再恢复均正常。
2. **连续改译文逐步回退**：对同一可见选区连续翻译两次（`添加划词译文` → `重新翻译`）→ 第一次 `Ctrl+Z` 浮条仍在（回到上一版，toast「已撤销：重新翻译」）→ 第二次 `Ctrl+Z` 浮条消失（toast「已撤销：添加划词译文」）。
3. **重启后仍可撤销**：上一进程保留 1 条高亮 + 1 条离屏划词译文（`history.json` 2 步）→ 结束进程重开 → 打开同一本书，面板显示 2 条 → `Ctrl+Z` 后 1 条（删译文）→ 再 `Ctrl+Z` 后 0 条（删高亮）。
4. **笔记撤销**：面板「编辑」→ 笔记卡写入「S7 撤销测试笔记」→ 保存后面板条目与贴边小字同步 → `Ctrl+Z` 回退为原文摘要。
5. **面板能力**：按章分组显示「第4章」；点击条目后面板关闭（跳转生效）；删除按钮对高亮与译文均可撤销。
6. **孤儿标记**：把 `anchor.blockIndex` 改为 99 后重启 → 启动提示「1 条找不到原段落」→ 面板条目出现「原文已删除」徽标。

## 七、坑与说明

- 撤销栈存整份快照，深度必须受控（内存 40 / 落盘 20）；历史只保存 undo 侧，重启后 redo 为空。
- 分页 iframe 的宽度可能远大于可视窗口，iframe 内 `getBoundingClientRect()` 不代表可见；译文贴边定位必须用父窗口 `innerWidth/innerHeight` 加 `frameElement` 偏移，离屏选区不渲染。本次曾因选到离屏同段文字误判「译文不出现」。
- 面板章标题依赖 `book.toc` 异步加载：`useMemo` 依赖加入 `panelOpen`，并在章节 `load` 时 bump 刷新型号。
- 详见 A07 §46。
