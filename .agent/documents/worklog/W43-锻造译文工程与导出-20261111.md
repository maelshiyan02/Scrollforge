## 一、目标

锻造从「保存会写母本」彻底改为「只写独立译文工程」：`译文/<语言代码>/章节/*.xhtml` + `mapping.json`；移除锻造「改写」通道；导出 `final export/<书名> - <语言>.epub`，保留母本图片/字体/样式。

验收：EPUB 书锻造保存成功且母本 SHA256 不变；导出 EPUB 可正常打开；未译段落有清单。

## 二、实现

### Rust 新增 `app/src-tauri/src/translate_project.rs`

- `save_project`：校验语言代码（防路径穿越）→ 把母本解包到 `译文/.build-<lang>/pkg` → 逐章读母本 XHTML，用 `apply_block_edits_ex` 只替换有译文的块（`BlockEdit.inner` 为 XML 转义后的纯文本）→ 写入 `译文/<lang>/章节/<NNN>-<原名>.xhtml`（保留 head、CSS、图片路径）。
- TXT 等非 EPUB 母本：按段落生成最小 XHTML（未译段落回落原文），`sourceHref = null`；导出明确拒绝。
- `mapping.json`：`schemaVersion/bookId/bookTitle/language/sourceName/sourceFingerprint/updatedAt/chapters[]/totals`；每章含 `chapterIndex/title/sourceHref/file/blockCount/translatedCount/untranslated[]`，未译序号用前端段落序号。临时文件 + rename 原子写。
- `export_project`：读 `mapping.json` → 解包母本到 `译文/.export-<lang>/pkg` → 按 `sourceHref` 覆盖为译文 XHTML → `pack_epub` 到 `final_export_dir/<书名> - <语言>.epub`。只读译文工程，不改写它。
- 临时解包根与 `pkg` 分开：`unpack_epub` 会在解包目录的父级建 `revisions`，分开放后清理一次性回收。

### `app/src-tauri/src/main.rs`

- `mod translate_project;`
- 新增命令：`translation_save`（书目录 + 母本指纹 + 章节数据）、`translation_export`（读设置里的 `final_export_dir`）、`write_forge_state`（只写 `forge.json` 注释覆盖层）。
- `commit_forge` / `restore_revision` 保留，但锻造面板不再调用。

### 前端

- `lib/forge.ts`：`ForgeEdit` 删除 `rewrite`；`hasEdit/parse/serialize` 收窄；删除 `normalizeRewrite`、`applyRewrites`、`ApplyResult`。
- `ForgePanel.tsx`：
  - 保存改为组装 `analysis.chapters + draft + epubFlatBlocks`（段落序号 + EPUB blockIndex + relPath）→ `translation_save` → `write_forge_state` 存注释；不再调用 `onCommitted`（母本未变）。
  - 移除历史版本区、diff 弹层、回滚确认与相关依赖；删除列表「改」徽标。
  - 新增导出按钮（TXT 母本禁用并提示「仅 EPUB 母本支持导出」）。
  - 新增未译清单：底部 `已译 X / Y · 未译 Z`，展开按章列出段落序号、点击跳转；长书限量渲染（最多 100 章 × 每章 20 段，其余折叠计数），避免 7 万段 DOM 卡死。

## 四、偏差与注意

- 锻造保存会把整本书的段落数据一次性传给 Rust（本次 74,327 段，解包/替换约数秒）。长书可接受，但后续可改为「只传有译文的块 + 后端自行统计未译」。
- `mapping.json` 的 `untranslated` 是显式序号数组，本次约 1 MB；仍低于 2 MB 异常阈值，但章节再多需要改区间压缩。
- 书库当前 17 本均为 EPUB，**TXT 母本的保存/导出未做 GUI 实测**；TXT 保存分支（生成 XHTML、导出明确拒绝）仅通过代码路径与编译检查。新建书向导在第二步「生成 EPUB」未完成创建（与本轮改动无关的既有问题），因此没有制造 TXT 测试书。
- 历史版本 / diff / 回滚 UI 已从锻造移除；母本版本回滚仍在编辑档。
