## 一、目标

锻造层从「单段编辑 + 段落列表 + 整章分屏」三套界面并存，收敛成**一整章逐段对照工作台**，并与编辑层的顶栏/工具栏/文件树形态对齐：

- 左半原文、右半译文，同一段落在同一行；行高取两侧较高者，空行也参与对齐（保持中轴行数对应）。
- 章节切换改由顶栏「文件树」按钮拉起章节抽屉；段落选择直接在分屏里点选，支持单选、Ctrl 加选、Shift 连选。
- 译文注释移到右侧每个对应段落的译文框下方。
- 新增第二条工具栏：左侧译所选 / 译本章 / 润色所选，右侧待保存计数 + 放弃 / 导出 / 保存。
- 底部工具栏右侧显示**当前章节**的未译段数与浮层清单（不再统计全书）。
- 母本仍然只读；译文只写草稿与译文工程。

## 二、实现

### `app/src/components/ForgePanel.tsx`

- 删除旧的三视图状态：`chapterView`、`syncScroll`、`srcScrollRef/dstScrollRef/chapSrcRef/chapDstRef/srcBlockRefs/dstBlockRefs/syncingRef`、`paraListRef`，以及 `syncPaneScroll/topBlockIndex/blockOffset/syncChapterScroll`。左右两栏合并进同一个滚动容器，按行天然对齐，不再需要按比例或按段滚动联动。
- 新结构：`forge-toolbar`（第二工具栏）→ `forge-body`（章节抽屉 + `forge-workbench`）→ `forge-foot`（底部工具栏）。
- `forge-workbench`：列头 `position: sticky` 放在滚动容器内，列宽与每个 `forge-row` 的 `grid-template-columns: 1fr 1fr` 严格同宽；行 `align-items: stretch`，左原文与右译文同高。
- 译文框 `textarea` 自动增高（`onInput` 调 `autosize`，切章/窗口变宽/批量翻译后用 `fitRows` 重算，`ResizeObserver` 只看宽度变化避免回流死循环），保证长译文把整行撑高而不是内部滚动。
- 选择：`selection: Set<number>` + `anchorRef`；`forge-row__src` 与译文侧徽标行可点选，`Ctrl/Cmd` 切换、`Shift` 从锚点连选；选中行 `.sel`（左侧 accent 竖线），当前行 `.on`。
- 工具栏：
  - 左：章节标题 + 引擎信息（语言对 / 风格 / 模式 / 术语数 / 记忆条数）、`译所选 N`、`译本章`、`润色所选`、定位下一处未译、批处理进度与停止、`重新对齐 N`、`孤儿译文 N`。
  - 右：`待保存 N 段` + 放弃 / 导出 / 保存（即原「倒数第二行」那组控件）。
- 翻译/润色改为批量：`translateMany(targets, label)` 与 `polishSelected()` 复用同一套进度、取消、回落统计；`译所选` 只翻选区（已有译文会重译），`译本章` 只补本章无译文段落，`润色所选` 只处理选区里有译文的段落。
- `chapterProgress` 改为遍历草稿键统计（不再每次输入扫全书 74k 段），章节目录显示「已译 / 总段数」。
- 章节抽屉：复用编辑层 `.edit-panel__tree` / `.edit-panel__veil` 样式与 `.forge-tree` 补充，列出全部章节与逐章进度，点击切章（选区归零并滚到段首），`Esc` 优先收抽屉。
- 未译清单：`untranslatedParagraphs` 只按当前章计算；底部右侧按钮展开浮层（`position: absolute` 向上弹），点段落跳转并选中。
- 注释：每个译文格内保留独立注释框；无注释且非当前段时显示「＋ 注释」，点开即显示输入框。注释仍只写 `forge.json`。

### `app/src/components/Reader.tsx`

- `ForgePanel` 新增 `onToolbar(state)` 上报 `{ treeOpen, toggleTree }`（导出 `ForgeToolbarState`），Reader 用 `forgeToolbarRef` 接收并触发一次重渲染。
- 三模式胶囊右侧新增「展开章节列表」按钮（`folder` 图标，展开态 `.on`），复用编辑层文件树按钮的位置与样式；`Esc` 先收锻造章节抽屉。

### `app/src/styles.css`

- 新增 `.forge-toolbar*`、`.forge-workbench*`、`.forge-row*`、`.forge-foot*`、`.forge-pop*`、`.forge-tree`；`.forge-body` 改为 `flex` 容器（`position: relative` 供抽屉定位）；删除与旧下拉/段落列表冲突的 `.forge-row` / `.forge-label` 规则。
- 原 `.forge-pairs` / `.forge-split` / `.forge-editor` 等旧类已不再被引用（本轮未逐条删除，避免误伤其他选择器；后续可统一清理）。

## 四、偏差与注意

- **不再有「整章 / 单段」两套视图**：S11 的滚动联动开关与单段双栏一并移除，分屏本身即整章视图；若后续需要「只看一段」的沉浸模式，应作为独立模式加回，而不是再拆两套 DOM。
- **换行对齐靠行盒**：实现方式是左右同属一个 grid 行、行高取较高者，而不是在两侧插入空行文本；语义上等价，且不会污染原文/译文内容。
- **选择作用域是段落号**：切换章节会清空选区；批量翻译/润色过程中选区变化不会改变已启动的任务（目标数组在启动时固化）。
- **注释只存锻造记录**：仍不进译文工程与母本；导出 EPUB 不含注释。
- **章节抽屉复用编辑层样式**：`.edit-panel__tree` 的位置/宽度/滚动行为与编辑层一致，锻造层只补了章节行排版；如果以后编辑层改抽屉结构，需要同时看锻造层。
- **旧样式未全清**：`.forge-split*` / `.forge-editor*` 等已无引用但保留在 `styles.css`，避免一次性大范围删除误伤；后续统一清理时再删。
