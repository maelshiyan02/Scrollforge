## 二、代码审计与修复

审计范围：`ForgePanel.tsx`（translateMany / resolveOverwrite / polishMany）、`translate.ts`（translateOne / translateBaiduBlocks / 术语掩码 / 记忆）、`translate_project.rs`、`forge-drafts.ts`、`undo-stack.ts`、`main.rs` 百度命令。

修复 3 处可确证问题：

1. **翻译记忆键忽略目标语言**（`lib/translate.ts`）：`tmKey` 固定拼 `from>zh`，`rememberTranslation` 固定写 `to:'zh'`。目标语言切到英/日/韩时，会把中文译文当命中直接返回。改为 `tmKey(from, source, to='zh')`，默认中文时键格式与旧版完全一致，历史记忆继续可用；`rememberTranslation` 增 `to` 参数；`ForgePanel` 回灌记忆时带 `prefs.translateTarget`。
2. **批处理跨章错位隐患**（`ForgePanel.tsx`）：`translateMany` / `polishMany` 闭包读当前 `chapterIndex` 与 `paragraphs`，覆盖确认弹层期间若切章，回填会写到新章。改为函数接收 `chapterNo`，按目标章取段落与草稿键，弹层传入 `ask.chapterNo`。
3. **译文工程章节路径未拒绝绝对路径**（`translate_project.rs`）：原逻辑只挡 `..`，`C:/...` 这类绝对 href 会让 `PathBuf::join` 逃出解包目录。新增 `normalize_href`，统一拒绝绝对路径、盘符冒号与 `..`，保存与导出两处共用。

未改动但已确认安全：草稿 400ms 防抖写盘（同一 doc 对象，落盘时取最新内容）、撤销栈合并窗口、百度两档串行队列与退避重试、`polishOne` 的模式分支。
