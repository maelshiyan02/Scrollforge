## 三、本轮三条任务（含代码锚点）

### 3.1 3D 书架换底（纯 CSS）

**目标**：把 `.rack-viewport` 的深棕木纹背景换成贴合软件的**黄白基底**，并把书架做得更像真实书架；书脊的轴测投影逻辑不动。

**文件**：`app\src\styles.css`
- `.rack-viewport`（约 L504–524）：棕色渐变 → 暖白背板
- `.rack-board`（约 L712–733）：木色降饱和、提亮
- `.rack-tail`（约 L699–709）、`.rack-index`（约 L734+）：当前是浅色文字，换底后必须改成深色，否则看不见
- `.book-slot:hover .book3d`（约 L571–574）：黑色投影 `0.5` 过重，换浅底后要减淡

**做法**
1. 基底用软件既有色：`--paper: #faf9f6`、`--bar: #f2efe9`（`styles.css` L2–6）。
2. 背板：暖白（如 `#f7f3ea → #eee7d9`）+ 极轻纸纹；不要照片级木纹贴图。
3. 搁板：浅木色（如 `#d8b78d → #c39c6b`），前沿留深一点的立面做厚度。
4. 补侧板 / 书挡 / 层板柔和投影：用 `linear-gradient` + `box-shadow`，不新增 DOM。
5. 保留 `.rack-shelf` 的 `--dx / --dy / --skew` 轴测参数与 `.book3d` 抽书动画。

**禁止**：改成拟物贴图；调整书脊宽度/间距算法；改 `Shelf3D.tsx` 的交互逻辑（本轮 CSS-only）。

**自查**：3D 视图截图，看黄白基底、书脊仍立体、暗部不发黑、`rack-tail/rack-index` 文字可读。

### 3.2 上一章 / 下一章

**目标**：顶栏在"上一页/下一页"之外补章级跳转。

**文件**：`app\src\components\Reader.tsx`
- 页级翻页：`flip()`（L483–495）
- 顶栏按钮：L679–694（`上一页（←）` / `下一页（→ 或 空格 / 滚轮）`）
- 目录数据：`toc` 状态；`flattenToc()`（L66–75）**已过滤掉无 href 的分组**；L424–427 兜底
- 当前条目：`relocate` 里 `detail.tocItem?.label`（L218），`detail` 还带 `fraction / cfi / range`

**做法**
1. 新增 `jumpChapter(dir: 1 | -1)`：以 `view.lastLocation?.tocItem?.href` 在 `toc` 里定位下标；找不到时用 `view.lastLocation.section.current` → `book.sections[i].id` 与 `toc[j].href.split('#')[0]` 比对。
2. 目标 = `toc[idx + dir]`；`await view.goTo(target.href)`；首/末条时按钮 `disabled`（`aria-disabled` + 中文 tooltip「已经是第一章 / 最后一章」）。
3. 分组目录天然跳过（`toc` 只含可跳转项），不要另写过滤。
4. 竖排（`vertical`）时**图标方向**跟随阅读方向（与现有页级按钮一致），但文字标签仍是「上一章 / 下一章」。
5. 无目录的 TXT/纯文本：用现有 `tocEntries`（`buildTxtBook` 已产出）同样可用；确实为空时禁用并提示「这本书没有目录」。
6. tooltip 中文 + 快捷键（若给快捷键才写进 tooltip；不给就不写）。

**验收**：第 1 章末点「下一章」进第 2 章首；第 1 章点「上一章」禁用；末章「下一章」禁用；分组目录不跳空；竖排下按钮方向不反直觉。

### 3.3 底部阅读进度条（参考 Thorium）

**目标**：底部状态栏加一条细进度条，可点击/拖拽跳转。

**文件**：`Reader.tsx`
- 状态栏 `footer.status`：L1009–1016（章节名 / 百分比 / 元信息 / 方向 / 模式）
- 内核能力：`view.goToFraction(frac)`（`vendor\foliate-js\view.js` L471）；进度来自 `relocate.detail.fraction`
- 样式：`styles.css` 追加 `.read-progress*`（不要动 `.status` 现有排版）

**做法**
1. 在状态栏上方/下沿叠一条 3–4px 细线（Thorium 风格：轨道浅灰 + 已读主色 + 可拖动圆点）。
2. 点击轨道 → 按点击位置换算 `frac` → `view.goToFraction(frac)`。
3. 拖拽：`pointerdown` 捕获 → 移动时只更新本地预览百分比 → `pointerup` 才 `goToFraction`（避免连续重排卡顿）。
4. 拖动期间显示「xx%」，松手后以 `relocate` 回填的真实 `fraction` 为准。
5. 不抢键盘/滚轮：进度条上 `stopPropagation`；分页、连续滚动、固定版式三种模式都要可用。
6. 无进度能力（极端情况 `fraction` 缺失）时隐藏进度条，不报错。

**验收**：拖到约 50% → 状态栏百分比≈50%；退出重进回到该位置；滚动模式与双页模式各测一次；拖动不触发翻页。
