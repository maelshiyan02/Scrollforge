## EPUB 编辑与制作 · 可行性分析（用户新指令）

- 参考对象：Calibre、Sigil（含 TXT 导入插件）、5s6 的「EPUB 电子书编辑器 v3.4.0 中文绿色版」。三家共性链路：结构 → 内容 → 元数据 → 目录 → 预览 → 校验 → 导出。
- 许可边界：Calibre / Sigil 均 GPL-3，只读交互与流程、不复制代码；5s6 来源与授权不明，不下载不打包；EPUBCheck 为 **BSD-3**（已核对本地 LICENSE.txt），OpenJDK 为 GPLv2+CE，两者都可随包分发。
- 用户拍板三项：① 源码 + 所见即所得**两者都要**；② 校验**必须内置开箱即用的完整 epubcheck**；③ 编辑范围**书库内 + 任意磁盘 EPUB**。
- 结论：可行。底座已有 `epub-writer.ts`（EPUB 3 写出）、`zip-store.ts`（ZIP 写）、书库 / 封面 / revisions / TXT 解析 / 转换向导；缺 ZIP 读取、OPF 解析模型、工作副本、双视图编辑。
- 关键设计：**块级回写**代替整篇 DOM 序列化——`quick-xml` 记录每个块的字节区间，只替换用户改动过的块，未改块逐字节保留，把 WYSIWYG 的破坏面压到最小。
- 分期：E1 打开/解包/源码编辑/内置校验 → E2 元数据与封面 → E3 目录与章节结构 → E4 双视图与块级所见即所得 → E5 从零做书。版本按 v0.7.0 起。
