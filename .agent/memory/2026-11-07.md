# 2026-11-07

## FEAT：护眼三档主题（日间 / 护眼 / 夜间）

- 调研结论：护眼不是「绿底」一种做法，而是「降蓝光 + 降色温 + 降对比 + 降亮度」的组合；护眼档纸面取柔和绿 `#E8F0E4`、文字 `#2E3A2C`（实测对比度 10.2:1）；夜间纸面取非纯黑 `#1B1D20`、文字暖灰 `#D0CCC6`（10.6:1）；日间保持原样。不做跟随系统与定时切换，默认日间，只在设置页与书架/阅读页顶栏手动循环（理由：Windows「夜间模式」是显示器色温层，无法被应用读取为可靠契约；阅读类 App 普遍提供手动档位）。
- 数据模型：`Prefs.theme: 'day' | 'eye' | 'night'`，复用 `scrollforge:prefs` 持久化；`THEMES` 白名单校验；`nextTheme()` / `themeLabel()` 统一循环与文案。
- 色板：`styles.css` 新增 ~40 个语义令牌（纸面/表面/文字/次要/描边/强调/状态/深度/编辑器/3D 书架/阅读正文），三套 `:root[data-theme]` 各一份，收敛 361+ 处硬编码色。
- 阅读器：`lib/theme.ts` 的 `applyReaderTheme()` 向每个 foliate 章节文档注入底色/文字/链接/图片滤镜；日间不注入，保持书籍原样。图片不反色，夜间仅 `brightness(0.86)`，包含 `background-image` 书封 `.cover.has-art` 单独规则。
- 入口：书架 `.subbar-tools` 与阅读页顶栏各加一个主题循环按钮（编辑页内也可见）；设置页新增「外观与护眼」功能卡（三档 select + 覆盖范围说明）。

## 两个真实缺陷（验证时发现并修复）

- 现象：切档后正文仍是上一档颜色，页面四周黑边残留。
  根因：① React effect 子先父后，`applyReaderTheme` 读令牌时根元素还没换档；② 分页器 `#background` 只在章节载入时写一次，shadowRoot 为 closed 无法外部修改。
  修复：`applyReaderTheme` 内先 `applyTheme(mode)` 再读；vendor `paginator.js` 加最小补丁 `refreshBackground()`，主题 effect 里调用。
- 现象：编辑页内无主题按钮；夜间书封不降亮。
  修复：主题按钮移出 `{!editOpen && ...}` 条件；补 `.cover.has-art` 滤镜规则。
