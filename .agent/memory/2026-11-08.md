## FEAT：自定义标题栏与书架排序双开关

- 现象：Windows 原生标题栏（白条）不随三档主题变化，且与下方应用顶栏标题重复；书架排序是文字下拉，与图标风格不统一。
- 根因：原生标题栏由 DWM 绘制，不在 DOM 内，CSS/主题变量无法影响；高度与按钮尺寸同样不可改。
- 改造：
  - `tauri.conf.json` 设 `decorations: false`，书架 `.shelf-bar` 升级为标题栏：24px 图标 + 18px 标题 + 右侧 46×56 最小化/最大化(还原)/关闭；阅读页 `.bar` 同步接入。
  - 新增 `WindowControls.tsx`（`getCurrentWindow` + `onResized` 同步最大化图标）；`capabilities` 补 5 项 window 权限。
  - `--titlebar-h: 56px`；窗口按钮贴边、悬停 `--surface-2`、关闭悬停 `--danger`，三档自动联动；`<1100px` 隐藏阅读页书名。
  - 排序改图标双开关：最近阅读/导入时间/书名 A-Z 循环 + 升/降序，放在第二行网格视图按钮左侧；`prefs.shelfSortOrder` 持久化，时间类默认降序、书名默认升序。
  - `public/app-icon.png` 从应用图标复制，不新画。
- 验收：`npm run build` / `cargo check` / `npm run tauri build` 通过；`build\Scrollforge.exe` 7,522,304 B（13:10:54）。CDP：顶栏 56px、窗口按钮 3 枚、三档顶栏与第二行同色、夜间列表白底扫描 0、排序正反序断言通过、最大化/还原正常、836px 两页无溢出、重启后档位与排序保持；最终启动 10s 存活且 9222 无监听。
- 取舍：按用户确认放弃 Snap Layout 与标题栏右键菜单；边缘缩放依赖 `WS_THICKFRAME`（style `0x14CF0000`），未逐边手工拖拽。
- 文档：W29 工作日志、W00 索引 W29 行、A07 §35（254–258）。
