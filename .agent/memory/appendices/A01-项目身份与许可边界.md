# A01 · 项目身份与许可边界

> 上级索引：`../MEMORY.md` §0 底线 1 ｜ 相关：A02 技术栈、A05 工作空间

**触发时机**：涉及项目定位、命名、引入任何第三方依赖、或"想抄一段别人的代码"之前。

## 1. 身份

| 项 | 值 |
|---|---|
| 英文名 | Scrollforge |
| 中文名 | 阅读锻造工坊（暂定） |
| 定位 | **桌面阅读器 + 编辑器**：读（多格式统一书架）/ 转（TXT→EPUB 核心流程）/ 改（覆盖层改写、翻译、注释，可写回、可回滚） |
| 目标平台 | Windows 桌面（不做移动端） |
| 包名/标识符 | `com.scrollforge.app` |

## 2. 许可边界（🔴 硬约束）

| 项目 | 许可证 | 我们能做什么 |
|---|---|---|
| foliate-js | **MIT** | ✅ 可直接引入、可改、需保留 LICENSE |
| readium/css | **BSD-3** | ✅ 可直接引入、需保留 LICENSE |
| Tauri / React / Vite / Tailwind / SQLite | MIT/Apache-2.0 | ✅ 正常依赖 |
| readest / read-aware / koodo-reader | AGPL-3.0 | ⛔ 只读架构，**一行都不能复制** |
| wenku8-flutter / calibre | GPL-2.0 / GPL-3.0 | ⛔ 只读交互与流程，**一行都不能复制** |

**判定法**：想复用某段代码时问三个问题——① 它的仓库许可证是什么？② 复制后本仓库会不会被迫改用 AGPL/GPL？③ 能不能只借"思路/算法/视觉数值"重写？答不出就不许复制。

**允许的借用**：算法思路、交互流程、信息架构、视觉数值（颜色/字号/间距/圆角这类事实不受版权保护）、命名预设。

## 3. 关键事实来源

- Readest：TanStack/Next 工程化 foliate 落地，25.7k star，AGPL。
- ReadAware：Tauri 2 + React 19 + Vite + Jotai + Tailwind v4 + foliate-js，单作者，AGPL，插件 API 包 MIT。
- 实测结论：ReadAware 的 TXT 章节逐行算法在《红楼梦》123/123 正确；Readest 的"先切段再匹配"算法在章间 8 空行时全盘失效。详见分析报告第十节。
