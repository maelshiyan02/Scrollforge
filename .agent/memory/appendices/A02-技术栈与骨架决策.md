# A02 · 技术栈与骨架决策

> 上级索引：`../MEMORY.md` §2 ｜ 相关：A01 许可、A06 构建

**触发时机**：搭环境、加依赖、决定目录结构、决定"这个功能用什么实现"之前。

## 1. 已定技术栈（2026-10-27）

| 层 | 选型 | 说明 |
|---|---|---|
| 桌面外壳 | Tauri 2 | 窗口、菜单、文件访问、全局快捷键、单实例 |
| 渲染内核 | **foliate-js**（vendor 引入，固定 commit） | EPUB/MOBI/KF8/FB2/CBZ/PDF；分页 `columnize` 与滚动 `scrolled`；竖排 `vertical-rl`/`vertical-lr`；CFI |
| 排版 CSS | readium/css（BSD-3） | 字号阶、行高、页边距、分栏、竖排细节 |
| 前端 | React 19 + TypeScript + Vite + Tailwind v4 | 不用 Next.js（桌面壳不需要 SSR，省掉一层复杂度） |
| 数据 | SQLite + FTS5 | 书架、进度、标注、覆盖层、revisions |
| TTS | 系统语音（默认）→ 在线引擎 → 离线音色包 | 引擎抽象层 |

## 2. 为什么不用 Next.js / 不 fork Readest

- Next.js 的价值在 SSR 与路由，桌面壳用不到；Tauri 官方模板即 Vite，构建产物更小、启动更快。
- fork Readest 会把项目绑成 AGPL 衍生作品，与"MIT 自建"拍板冲突（见 A01）。

## 3. 目录约定（`app/` 为工程根）

```
app/
  src/                 前端（React）
  src/vendor/foliate-js/   渲染内核（MIT，保留 LICENSE，改动集中在此便于日后替换）
  src-tauri/           Rust 端 + tauri.conf.json
build/                 交付产物（Scrollforge.exe）
```

## 4. 环境事实（本机）

- Node 24 / npm 11（`node` 在 PATH）。
- Rust 1.98.1 位于 `D:\dev\rust`：**必须先设** `CARGO_HOME=D:\dev\rust\cargo`、`RUSTUP_HOME=D:\dev\rust\rustup`，并把 `D:\dev\rust\cargo\bin` 加进 PATH，否则 `cargo` 不可用。
- MSVC：Visual Studio Community 2022（含 VC Tools x64）已装，Tauri 可直接编译。
- **没有 pnpm**：一律用 `npm`，不要写 pnpm 命令。
- **Java（2026-10-29 升级）**：Microsoft OpenJDK **21.0.13 LTS** 装在 `D:\Program Files\jdk-21`（328 MB）；机器级 `JAVA_HOME` 指向它，PATH 首位是 `D:\Program Files\jdk-21\bin`。`java` / `javac` / `jlink` / `jar` 全局可用，epubcheck 4.2.6 已用默认 `java -jar` 实跑通过。
  - 旧 JDK 8（`D:\Program Files\jdk1.8.0_202`）**保留但已移出 PATH**，需要时用全路径调用（兼容老项目）。
  - Oracle 的两个 32 位 shim（`...\Oracle\Java\java8path`、`...\javapath`）已从 PATH 删除——它们必崩 `0xC0000409`，是之前 epubcheck 跑不起来的根因（A07 第 82 条）。
  - Maven 3.9.15 现在跑在 Java 21 上；若有 Java 8 项目，改用 `JAVA_HOME=D:\Program Files\jdk1.8.0_202` 临时覆盖，不要改回全局。
- **系统 TTS 不存在（2026-10-29 实测）**：`HKLM\SOFTWARE\Microsoft\Speech\Voices\Tokens` 与 `...\Speech_OneCore\Voices\Tokens` 都不存在，`System.Speech.GetInstalledVoices()` 报"系统上未安装语音" → 朗读功能**不能依赖系统音色**，必须内置（Piper）。
- **硬件**：i5-14600KF（14C/20T）、31.8 GB RAM、RTX 5070（12 GB，驱动 32.0.15.9186）、Win11 26100；D 盘剩约 699 GB。
- **jlink 可用**：裁剪 epubcheck 运行时实测 46.1 MB（zip 31.0 MB），产物在 `_tools/jre21-epubcheck/`。
