# A03 · 界面交互硬约束

> 上级索引：`../MEMORY.md` §0 底线 3 ｜ 相关：A01 视觉可借用范围、A04 功能范围

**触发时机**：任何改 UI、加按钮、做设置页、做菜单、写文案之前。**这些是验收项，不是建议。**

## 1. 八条硬约束

1. **侧栏收起不隐藏**：左右栏折叠成 48–56px 图标条，悬停浮出；上下条折叠成 32px 细条。PC 版不追"全屏只剩文字"。
2. **全中文**：按钮、菜单、设置项、tooltip、错误提示一律中文；不混英文缩写（"TTS"可写"朗读"）。
3. **按钮一律图标化（2026-10-28 用户新指令，覆盖旧版"有文字的用文字"）**：所有按钮只放图标，统一用 Material Icons（`Icon` 组件 + `.mi` 类，与 Flutter 同源实心风格），按钮上原来的中文改为 `data-tip` 悬停浮出的中文说明，同时必须给 `aria-label`。工具条按钮用 `.btn.icon-only`（32px），面板内用 `.btn.small.icon-only`（26px），底部弹窗加 `.tip-top`。图标要"见形知意"（check=确定、close=取消、save=保存、restore=回滚、difference=差异、history=版本）。**唯一例外**：右键/更多菜单的列表行保留中文文字，且文字前加图标。
4. **高频一级可达**：单页↔双页、字号、主题、目录、朗读，必须在「工具栏 / 右键菜单 / 命令面板 Ctrl+Shift+P / 快捷键」中任一路 **1 步**完成。禁止把"双页切单页"藏在设置里。
5. **预设优先**：阅读模式、排版方案、TTS 音色都给 3–6 个**有中文名字**的预设（如"雾松""浅海""日文轻小说·竖排右→左"），自定义排在预设之后。
6. **桌面密度**：常显章节名、页码、百分比、当前模式。
7. **TTS 开箱可用**：装完即听；引擎/音色/环境音属进阶配置。
8. **后台不抢焦点**：导入、转换、预缓存、自动更新一律后台，不弹前台窗口。

## 2. 不要做的

- 零 chrome 阅读面、纯图标工具栏、单一浮动胶囊入口、把分栏/翻页藏在二级设置。
- 界面里出现英文功能名（ReadAware 的插件页就是因为英文长名被截断成 `Image Backgro…`，是反面教材）。

## 3. 交互规格（已确认要做的）

| 项 | 规格 |
|---|---|
| 双模式 | 专注阅读 / 工作台，`F11` 切换，共享状态不丢位置 |
| 方向 | 三个独立开关：文字方向（横排/竖排）、翻页方向（左→右/右→左）、自动识别（读 `page-progression-direction` + `lang="ja"`，命中只提示一次） |
| 翻页形态 | 平移 / 覆盖 / 淡入 / 瞬时 / 双页跨页 / 连续纵向滚动 / 连续横向滚动 / 缩放固定版式；卷页列 P2 |
| 组合轴 | 阅读模式 × 动画 × 分栏（单/双/自动）三轴独立，每个组合进预设 |
| 彩页 | 保持原色（默认）/ 融入纸色 / 夜间柔化；彩页单独成页 |
| 鼠标 | `Ctrl+滚轮` 缩放 50%–400%（与字号独立，按书记忆）；滚轮翻页或平滑滚动可切；`Shift+滚轮` 横向 |
| 键盘 | `Esc` 返回上一级（层级栈：全屏 → 关弹层 → 退锻造 → 回书架）；空格/PageUp/PageDown/←→ 翻页，竖排 RTL 时左右反转 |
| 说明书 | `F1` 打开，快捷键表**从命令注册表自动生成**，每个设置项一句人话解释 |

## 4. 视觉来源划分

- 阅读区：Readest 的干净克制（**只借观感，不抄代码**）。
- 书架：Koodo 的桌面级密度（网格/列表双视图、分组、排序、右键菜单）。
- 设置页：Wenku8 的编号分节 + 一句解释 + 命名预设。
- 排版数值：ReadAware 的字号阶/行高/页边距/纸色（数值属事实，可用）。
