# A04 · 功能范围与优先级

> 上级索引：`../MEMORY.md` §2 ｜ 相关：A03 界面约束

**触发时机**：排期、判断某功能是否本期做、被临时需求打断之前。

## 1. 阶段划分

| 阶段 | 内容 | 验收 |
|---|---|---|
| **Phase 0** | 最小可跑闭环：打开 EPUB → 分页 → 翻页 → 竖排切换 → 记进度 | `build/Scrollforge.exe` 双击可读一本 EPUB，重开回到原位 |
| Phase 1 | 书架 + TXT 阅读（逐行章节识别、硬换行熔接） | 《红楼梦》TXT 120 回齐全（1–120 无缺号） |
| Phase 2 | 转换向导（TXT→EPUB）+ 脚注气泡 + 标注 | 转换产物可被第三方阅读器正确打开 |
| Phase 3 | 锻造层：改写/翻译/注释 + 写回 + revisions 回滚 | 改一段、保存、回滚、再保存，全程可 diff |
| Phase 4 | TTS、竖排细节、彩页策略、内置说明书、命令面板 | 装完即听；F1 可查所有快捷键 |
| P2 可选 | 卷页动画、插件化扩展 | — |

## 2. 功能清单（来源标注）

| 功能 | 来源 | 本期 |
|---|---|---|
| 分页 + 连续滚动 | foliate-js | P0 |
| 竖排 / RTL | foliate-js | P0（切换开关）/ P4（细节打磨） |
| CFI 进度 | foliate-js | P0（先 localStorage）/ P1 仍 localStorage（用户决定），SQLite 后移 |
| 逐行 TXT 章节识别 | 自写（读 ReadAware 思路重写） | P1 |
| 硬换行熔接 | 自写（两款都没做，差异化点） | P1 |
| TXT→EPUB 转换向导 | 自写 | P2 |
| 脚注气泡 | foliate-js `footnotes.js` + 换肤 | P2 |
| 标注/高亮/搜索 | 自写 | P2/P3 |
| 锻造覆盖层 + revisions | 自写 | P3 |
| TTS 引擎抽象 | 自写 | P4 |
| 内置说明书 | 自写 | P4 |

## 3. 明确不做

- 移动端 / iPad 版；云同步；书城与订阅；账号体系。
- 抄袭任何 AGPL/GPL 代码（见 A01）。
