# A06 · 构建发布与版本号

> 上级索引：`../MEMORY.md` §0 底线 3 ｜ 相关：A02 技术栈、A07 踩坑

**触发时机**：打包、出 exe、改版本号、写发布说明之前。

## 1. 版本号规则

- 采用 `0.MINOR.PATCH`，Phase 内递增 PATCH，跨 Phase 递增 MINOR。
- **单一真相**：`app/package.json`、`app/src-tauri/tauri.conf.json`、`app/src-tauri/Cargo.toml` 三处版本号必须一致；改版本时三处同改。
- 每次出包在本文件 §4「版本记录」追加一行，并写进当日 `memory/YYYY-MM-DD.md`。

## 2. 交付产物

- 路径固定：`<项目根>/build/Scrollforge.exe`（用户双击即可运行）。
- 生成方式：`npm run tauri build -- --no-bundle` → 从 `app/src-tauri/target/release/` 复制 exe 到 `build/`。
- 图标：源文件 `<项目根>/icon.png`，经 `npx tauri icon` 生成全套图标进 `app/src-tauri/icons/`。

## 3. 构建命令（PowerShell 5，注意不支持 `&&`）

```powershell
$env:CARGO_HOME="D:\dev\rust\cargo"; $env:RUSTUP_HOME="D:\dev\rust"; $env:Path="D:\dev\rust\cargo\bin;"+$env:Path
Set-Location "<项目根>\app"
npm run tauri build -- --no-bundle
```

## 5. 已验证的构建事实（2026-10-27）

- 冷构建约 2.5 min，增量约 1 min；前端 ~0.8 s。
- `build/Scrollforge.exe` 需**先关闭正在运行的实例**再复制，否则 `Copy-Item` 报"文件正由另一进程使用"。
- 验证纪律：WMI 启动 + `SetProcessDPIAware` + `PrintWindow(hwnd, hdc, 2)`，全程不进前台（见 A07 §2）。
- 需要 CDP 自动化时：临时在 `tauri.conf.json` 的 `app.windows[0]` 加 `"additionalBrowserArgs": "… --remote-debugging-port=9333"` 并 `npm run tauri build`；**交付前必须删掉该字段并重新构建**，否则交付 exe 一直开着调试端口（v0.3.0 已按此执行并实测端口关闭）。
