### 教训

1. **FGP jar 和 AGP 9.x 不兼容**（Flutter 3.47.5 的小 bug）——别硬升 AGP
2. **ANDROID_HOME 被覆盖**——必须 Machine + User 都设
3. **AS 自己的配置文件和环境变量是两套系统**——改了 env 还要改 xml
4. **Device Manager headless 预览强制 SwiftShader**——卡死，必须点 ▶ 正常启动
5. **emulator -no-window 的 lock 文件循环创建**——explorer 疯狂刷新元凶
