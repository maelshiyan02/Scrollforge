## 技术规范

### 网站抓取

1. **NovelUpdates** 优先（信息最全：作者/标签/评分/章节数）
2. **NovelFire** 其次（正文抓取，需要章节列表和 HTML）
3. 如果有 Cloudflare 或 JS 渲染 → 用 browser-use 插件或 DrissionPage
4. 代理已配 127.0.0.1:7890（Clash）

### EPUB 制作规范

- 格式：EPUB 3.0
- 目录：Cover → Title Page → Table of Contents → Chapters → Colophon
- 封面：用我备好的封面（PNG/JPG），嵌入 Cover 页
- 章节命名：`Chapter 001.xxx`（三位补零，方便排序）
- 清理：去广告、去页眉页脚、去导航链接
- 参考 `Novel_Store\EPUB_Conversion_Notes.md` 的完整流程

### Wenku8 导入

- 路径：`/sdcard/Download/`
- 首次扫描要开 Android MANAGE_EXTERNAL_STORAGE 权限
- App 解析后存私有目录（gzip 压缩章节）

## 历史坑点

1. **Pixel 10a 模拟器必须用 Device Manager ▶ 正常启动**——命令行 headless 强制 SwiftShader 卡死
2. **ANDROID_HOME 被覆盖**——Machine + User 级都要设
3. **Gradle wrapper 9.1.0 + AGP 8.11.1 是 Flutter 3.47.5 的最优组合**——AGP 9.x 会崩（FGP jar 不兼容）
4. **Android Studio 自己的 SDK 配置是 xml 文件**——环境变量改了不代表 AS UI 里生效
5. **Flutter daemon 不要随便杀**——断了 AS 里的设备列表
6. **残留 conhost 会积累**——工作结束可以清理
